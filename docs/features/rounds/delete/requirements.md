# rounds/delete

## 目的

利用者が、不要になったラウンドを、一覧と詳細から確認のうえ削除し、削除したラウンドが表示されないようにする。

## 要求

### 一覧から削除する

- ラウンド一覧でラウンドのカードのメニューボタンを押すと、メニューが開き、削除を選べる。
- メニューを開いているときにメニューの外を押すと、メニューが閉じる。
- メニューで削除を選ぶと、記録したスコアがすべて失われることを示す確認ダイアログが開く。
- 一覧の確認ダイアログは、名前のあるラウンドではその名前を引用し、名前の無いラウンドでは名前を引用しない。
- カードのメニューボタンの読み上げ名は、名前のあるラウンドではその名前を引用し、名前の無いラウンドでは「ラウンドのメニュー」になる。
- 確認ダイアログで確認すると、ダイアログが閉じ、そのラウンドが一覧から消える。

### 詳細から削除する

- ラウンドの詳細でヘッダーのメニューボタンを押すと、メニューが開き、ラウンドの削除を選べる。
- メニューでラウンドの削除を選ぶと、ラウンドの名前を引用せず、記録したスコアがすべて失われることを示す確認ダイアログが開く。
- 確認ダイアログで確認すると、ラウンド一覧へ移り、そのラウンドは一覧に表示されない。
- 詳細から削除した後にブラウザの戻るを押しても、削除したラウンドの詳細へ戻らない。

### 確認をやめる

- 確認ダイアログは、キャンセル、ダイアログの外のクリック、Escキーのいずれでも、ラウンドを削除せずに閉じる。

### オフラインのとき

- オフラインでも、一覧で削除を確認すると、ダイアログがすぐ閉じ、そのラウンドが一覧から消える。
- オフラインでも、詳細で削除を確認すると、ラウンド一覧へ移る。
- オフラインで削除したラウンドは、オンラインに戻った後に再読み込みしても、一覧に表示されない。
- オフラインで作成したラウンドをオフラインのまま削除しても、オンラインに戻った後に再読み込みすると、一覧に表示されない。

### 削除の送信が終わる前、削除が拒否されたとき

- 削除の送信が終わる前に一覧を再読み込みしても、削除したラウンドは表示されない。
- 削除する権限が無く削除が拒否されたときは、一覧を再読み込みするとラウンドが再び表示され、エラーメッセージは表示されない。

## 対象外

- 一覧の取得と、削除したラウンドを除いた一覧の組み立ては、rounds/historyで扱う。
- 削除したラウンドを開いたときの「ラウンドが見つかりません。」の表示は、rounds/detailで扱う。
- 削除の送信と、削除の前後に届いた記録の扱いは、rounds/syncで扱う。
- 削除の取り消しと、削除が拒否されたことの通知は扱わない。
- 別のタブで行った削除を、開いている一覧へすぐ反映することは扱わない。
