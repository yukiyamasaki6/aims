# rounds/delete

## 目的

利用者が、不要になったラウンドを、一覧と詳細から確認のうえ削除し、削除したラウンドが表示されないようにする。

## 要求

### 一覧から削除する

- ホームの入力中のカードと履歴のカードで、メニューボタンを押すと、メニューが開き、削除を選べる。
- メニューを開いているときにメニューの外を押すと、メニューが閉じる。
- メニューで削除を選ぶと、記録したスコアがすべて失われることを示す確認ダイアログが開く。
- ホームと履歴の確認ダイアログは、名前のあるラウンドではその名前を引用する。
- ホームと履歴の確認ダイアログは、名前の無いラウンドでは名前を引用しない。
- カードのメニューボタンの読み上げ名は、名前のあるラウンドではその名前を引用する。
- カードのメニューボタンの読み上げ名は、名前の無いラウンドでは「ラウンドのメニュー」になる。
- 確認ダイアログで確認すると、ダイアログが閉じ、そのラウンドが一覧から消える。

### 詳細から削除する

- ラウンドの詳細でヘッダーのメニューボタンを押すと、メニューが開き、ラウンドの削除を選べる。
- メニューでラウンドの削除を選ぶと、ラウンドの名前を引用せず、記録したスコアがすべて失われることを示す確認ダイアログが開く。
- 詳細で確認ダイアログで確認すると、遷移元のビュー(履歴から開いた詳細では履歴、それ以外ではホーム)へ移り、そのラウンドはホームにも履歴にも表示されない。
- 削除の保存が終わる前に別の画面へ移ると、保存が終わっても、元の遷移で遷移元へ引き戻されない。
- 詳細から削除した後にブラウザの戻るを押しても、削除したラウンドの詳細へ戻らない。

### 確認をやめる

- 確認ダイアログは、キャンセル、ダイアログの外のクリック、Escキーのいずれでも、ラウンドを削除せずに閉じる。

### オフラインのとき

- オフラインでも、一覧で削除を確認すると、ダイアログがすぐ閉じ、そのラウンドが一覧から消える。
- オフラインでも、詳細で削除を確認すると、遷移元のビューへ移る。
- オフラインで削除したラウンドは、オンラインに戻った後に再読み込みしても、ホームにも履歴にも表示されない。
- オフラインで作成したラウンドをオフラインのまま削除しても、オンラインに戻った後に再読み込みすると、ホームにも履歴にも表示されない。

### 削除の送信が終わる前、削除が拒否されたとき

- 削除の送信が終わる前にホームや履歴を再読み込みしても、削除したラウンドは表示されない。
- 削除する権限が無く削除が拒否されたときは、ホームや履歴を再読み込みするとラウンドが再び表示され、エラーメッセージは表示されない。

## 対象外

- 履歴の取得と、削除したラウンドを除いた表示の組み立ては、rounds/historyで扱う。
- 削除したラウンドを開いたときの表示(「ラウンドが見つかりません。」と「戻る」リンク。遷移元へは移動しない)は、rounds/detailで扱う。
- 削除の送信と、削除の前後に届いた記録の扱いは、rounds/syncで扱う。
- 削除の取り消しと、削除が拒否されたことの通知は扱わない。
- 別のタブで行った削除は、再読み込みで反映される。開いているホームや履歴へすぐ反映することは扱わない。
