# rounds/delete

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| delete-01 | ラウンド一覧でラウンドが1件以上ある | メニューボタンをクリックする | メニューが展開される |
| delete-02 | メニューを展開したラウンド一覧 | 削除ボタンをクリックする | ラウンド削除確認ダイアログが開く |
| delete-03 | ラウンド削除確認ダイアログ（ラウンド一覧）で削除が成功する | 確認ボタンをクリックする | ダイアログが閉じられ、ラウンドが一覧から消える |
| delete-04 | ラウンド詳細画面 | メニューボタンをクリックする | メニューが展開される |
| delete-05 | メニューを展開したラウンド詳細画面 | 削除ボタンをクリックする | ラウンド削除確認ダイアログが開く |
| delete-06 | ラウンド削除確認ダイアログ（ラウンド詳細画面）で削除が成功する | 確認ボタンをクリックする | /roundsへ遷移し、ラウンドが一覧に表示されない |
| delete-07 | メニューを展開したラウンド一覧 | 外側をクリックする | メニューが閉じられる |
| delete-08 | ラウンド削除確認ダイアログ | キャンセルボタンをクリックする | ダイアログが閉じられる<br>ラウンドが削除されない |
| delete-09 | ラウンド削除確認ダイアログ | 背景をクリックする | ダイアログが閉じられる<br>ラウンドが削除されない |
| delete-12 | オフラインのラウンド一覧 | 削除を確認する | ダイアログがすぐに閉じられ、ラウンドが一覧から消える |
| delete-13 | オフラインのラウンド詳細画面 | 削除を確認する | /roundsへ遷移する |
| delete-14 | オフラインでラウンドを削除した | オンラインへ復帰する | 再読み込みしてもラウンドが一覧に表示されない |
| delete-15 | オフラインで開始したラウンドを、オフラインのまま削除した | オンラインへ復帰する | 再読み込みしてもラウンドが一覧に表示されない |
| delete-16 | 削除の送信が完了していない | ラウンド一覧を再読み込みする | ラウンドが一覧に表示されない |
| delete-17 | 削除が認可で拒否される | 削除を確認し、一覧を再読み込みする | ラウンドが一覧に再び表示され、エラーメッセージは表示されない |
