# rounds/preset

## 目的

利用者が、よく使う構成をプリセットとして残し、不要になったプリセットを消せるようにする。

## 要求

### プリセットとして保存する

- ラウンドの画面で「プリセット保存」を押すと保存ダイアログが開き、名前欄のプレースホルダーに、距離構成から作った名前が表示される。
- 保存すると、画面に表示中の構成(編集した直後の構成を含む)が個人プリセットとして保存され、ダイアログが閉じる。
- 名前が空のときは、プレースホルダーに表示された距離構成から作った名前で保存される(距離が1つ以上あるときの規則)。
- 保存したプリセットは、その後オフラインで開いても、ラウンド作成画面の個人プリセットに表示される。
- 保存ダイアログの背景を押すと、保存せずにダイアログが閉じる。

### 保存を待つ間、失敗したとき

- 保存が完了するまでは、保存ボタンを押せない。
- 保存が完了するまでは、背景を押しても保存ダイアログは閉じない。
- 距離が1つもないラウンドでは、保存ダイアログを開いた時点から保存できない旨が表示され、保存ボタンを押せない。
- 名前が51文字以上のとき、または保存に失敗したときは、エラーが表示され、ダイアログは開いたままになる。
- 保存の応答が10秒以内に得られないときは、失敗が表示され、ダイアログは開いたままになる。

### プリセットを削除する

- ラウンド作成画面の個人プリセットのメニューから削除を選ぶと、メニューが閉じて確認ダイアログが開く。
- 確認すると、ダイアログが閉じ、プリセットが一覧から消え、再読み込みしても現れない。
- 選択中のプリセットを削除して確認すると、選択も解除される。
- 確認のキャンセルか背景のクリックでは、ダイアログが閉じるだけで削除されない。
- 削除が完了するまでは、キャンセルと確認を押せない。
- 削除の応答が10秒以内に得られないときは、失敗が表示され、確認ダイアログは開いたままになる。
- 削除が完了するまでは、背景を押しても確認ダイアログは閉じない。

## 対象外

- プリセットの名前の変更と内容の編集は扱わない。
- 公式プリセットの保存と削除は扱わない。
- プリセットの一覧と選択、プリセットからの開始は、rounds/startで扱う。
