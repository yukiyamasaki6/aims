# rounds/detail

## 目的

利用者が、ラウンドの記録と、ラウンド全体と距離ごとの成績を確かめられるようにする。

## 要求

### 詳細を開く

- 認証済みで、存在するラウンドを開くと、スコアカードが表示される。
- 記録済みの得点があるラウンドを開くと、ラウンド結果に合計が、距離結果に距離ごとの小計が表示される。
- 距離結果には、その距離の的にXリングがあればX数と最高点数が、なければ最高点数と次点数が表示される。

### 長いスコアカードをスクロールするとき

- 1画面に収まらないラウンドをスクロールしても、ラウンド結果が隠れずに見える。
- 距離が複数あるラウンドで、別の距離のエンドまでスクロールしても、その距離の距離結果が隠れずに見える。

### 点数を記録したとき

- 的にXリングがある距離で、テンキーの点数ボタンを押すと、ラウンド結果の合計、距離結果の小計、ラウンド結果と距離結果のX数と最高点数が更新される。

### 入力中と完了のラウンドを開いたとき

- 入力中のラウンドを開くと、矢数に達していない最初のエンドに仮の矢が表示され、テンキーが展開される。
- 入力中で距離がないラウンドを開くと、ラウンド編集ダイアログが開く。
- 完了のラウンドを開くと、矢数に達していないエンドがあっても、仮の矢は表示されず、テンキーは展開されない。
- 完了のラウンドを開くと、距離がなくても、ラウンド編集ダイアログは開かない。

### ほかの画面へ進む

- 「一覧へ戻る」リンクを押すと、ラウンド一覧へ移動する。

### オフラインのとき

- ラウンドは端末にあるが的の一覧を端末に保存していないときは、オフラインで開くと、ラウンドの内容は表示されず、「ネットワークに接続されていません」が表示される。
- 的の一覧を端末に保存していないために「ネットワークに接続されていません」が表示されているときに、オンラインに戻ると、ラウンドの内容が表示され、「ネットワークに接続されていません」は表示されなくなる。
- 的の一覧を端末に保存済みなら、オフラインで、作成が未確定で距離があるラウンドでも、テンキーに的に応じた点数ボタンが表示され、点数ボタンを押すとラウンド結果の合計が更新される。
- オンラインでプリセットを選んで開始し、作成が未確定のままオフラインになったラウンドを開くと、全ての距離に的のサイズと図が表示される。
- 他の端末で作成し記録した入力中のラウンドは、この端末で一度も開いていなくても、オンラインで取得を済ませた後なら、オフラインで再起動して開いても、距離・記録済みの点数・的・合計が表示され、矢数に達していない最初のエンドに仮の矢が表示され、テンキーが展開される。

### 応答が遅いとき、セッションを確かめ直すとき

- オンラインのまま通信が応答しないときも、端末が保持する入力中のラウンドで、的の一覧を端末に保存済みなら、通信の開始から1秒以内にラウンドが表示される。
- 端末に開ける内容がない完了のラウンドを開くときに、セッションの更新が別の書き手の更新と重なると、更新が終わるまで読み込み中と表示されてエラーメッセージは表示されず、更新が終わるとスコアカードが表示される。
- 端末に表示できる内容がある入力中のラウンドで、的の一覧を端末に保存済みなら、開くときのセッションの更新が終わらなくても、端末の内容でラウンドが表示され、エラーメッセージは表示されない。
- 端末にセッションがあり、ラウンドの取得が一度だけ認証の拒否で返っても、「サインインが必要です。」は表示されず、スコアカードが表示される。

### ラウンドが見つからないとき、取得できないとき

- 存在しない、閲覧権限がない、または論理削除済みのラウンドを開くと、枠内に「ラウンドが見つかりません。」と「一覧へ戻る」リンクが表示される。
- 端末の内容で表示しているラウンドが、他の端末で削除されていたと分かると、ラウンド一覧へ移動する。
- 端末にオフラインで開ける内容がないラウンドを開いて通信できないときは、「一覧へ戻る」リンクと「読み込めませんでした。」と再試行ボタンが表示される。
- 取得がエラーになるときは、エラーメッセージが表示される。
- 他のタブが端末の保存の読み書きを続けているときは、開いてから10秒後に、「一覧へ戻る」リンクと「読み込めませんでした。」と再試行ボタンが表示される。

## 対象外

- 点数の入力と修正は、rounds/score-entryで扱う。
- ラウンドの設定と距離の編集は、rounds/setupで扱う。
- 入力の完了は、rounds/completionで扱う。
- ラウンドの削除は、rounds/deleteで扱う。
- 点数やラウンドの送信と同期は、rounds/syncで扱う。
- 端末にオフラインで開ける内容がないラウンドのオフラインの表示と、その表示からのオンライン復帰は、app/offline-pwaで扱う。
- 未認証で開いたときのサインイン画面への移動は、app/navigationで扱う。
- 的が異なる距離を含むラウンドの、ラウンド全体の最高点数とX数は扱わない。
- オフラインの間に、最後の取得の後に他の端末で行った削除・完了・記録を表示することは扱わない。
