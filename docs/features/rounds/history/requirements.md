# rounds/history

## 目的

利用者が、入力中のラウンドをホームから、完了したラウンドを履歴から見つけて開けるようにする。

## 要求

### ホームを開く

- 認証済みで開くと、端末の記録の入力中のラウンドが、名前・実施日・合計点で、実施日の新しい順に全件表示される。
- 入力中のラウンドの欄は常に展開され、折りたたみの操作と件数バッジはない。見出しも、完了したラウンドなど履歴由来の表示もない。
- 入力中のラウンドが0件のときは、欄は表示されず、「入力中のラウンドはありません」とだけ表示される。同期の取得中・失敗・オフラインでも同じである。
- 他の端末で始めた入力中のラウンドは、同期が端末の記録に取り込んだ後に表示される。新しい端末では、同期の初回の取得が完了するまで表示されない。
- 開くときにセッションの更新が別の書き手の更新と重なっても、「サインインが必要です。」は表示されず、ラウンドが表示される。
- アプリの起動、サインインの完了、他の画面から戻ると、ホームが開く。前回のビューは復元しない。

### 履歴を開く

- ホームとレフトパネル/ドロワーの「履歴」項目から開く。再読み込みや直接のアクセスでも開ける。
- 履歴の項目から開くと、最新の内容を取得し(戻る操作で履歴に戻ったときは「履歴へ戻ったとき」)、サーバーで完了と記録されたラウンドだけが、名前・実施日・合計点で、見出しなしで、一定件数ずつ表示される(「ページ送り」)。条件を選んでいないときは実施日の新しい順に並ぶ。
- 入力中のラウンドは、他の端末で入力中で端末の記録に未取り込みのものを含め、表示されない。同じラウンドがホームと履歴の両方に表示されない。
- 端末の記録だけで完了のラウンド(オフラインで完了した、またはサーバー未反映のもの)は、取得の成否にかかわらず表示されない。
- 続きがなく、表示するラウンドが0件のときだけ、完了したラウンドがないときも条件に一致するラウンドがないときも、区別せず「該当するラウンドがありません」が表示される。続きがあって表示するラウンドが0件のとき(端末側の除外で表示済みのページが空になったとき)は、この文言は表示されず、続きを表示できる(「ページ送り」)。
- 取得中はスケルトン、通信できないときは「読み込めませんでした。」と再試行ボタン、オフラインのときは「ネットワークに接続されていません」が、履歴の中に表示される。この間、ラウンドは表示されない。
- オンラインのまま取得が応答しないときも、ホームの表示には影響しない。
- 開くときにセッションの更新が別の書き手の更新と重なっても、「サインインが必要です。」は表示されず、ラウンドが表示される。

### 並べ替えと絞り込み

- 履歴で、並べる基準として日付と得点のどちらか1つを選び、昇順・降順を切り替えられる。基準が同じラウンドは、実施日の新しい順、それも同じなら作成が新しい順に並び、再読み込みしても変わらない。
- 履歴の上端で、種別(アウトドア/インドア/フィールド)と弓種(リカーブ/コンパウンド/ベアボウ)をそれぞれ1つ選んで絞り込める。両方を選ぶと、両方に一致するラウンドだけが表示され、解除すると絞り込みなしに戻る。選択肢の表示名は画面の既存の表記と同じである。
- 期間として、実施日の開始日と終了日を指定して絞り込める。片方だけも指定できる。開始日だけなら実施日がその日以降、終了日だけなら実施日がその日以前、両方ならその間のラウンドだけが表示される。開始日と終了日の当日を含む。「直近1か月」などの簡易な選択は持たない。
- 得点の範囲として、下限と上限を指定して絞り込める。片方だけも指定できる。範囲の対象は合計点で、合計点が下限以上・上限以下のラウンドだけが表示される。境界の値を含む。
- 期間と得点の範囲は、指定を解除すると絞り込みなしに戻る。
- 距離の構成として、ラウンドを構成する距離を、射つ順に行として選んで絞り込める。行は末尾に追加し、行ごとに削除できる。行の並べ替えの操作はなく、順序を直すときは削除して追加し直す。同じ距離を複数回選べる。
- 距離の構成が一致するラウンドだけが表示される。一致とは、ラウンドの行の個数が選んだ行の個数と等しく、先頭から順に、各行が選んだ行と1対1で一致することである。50m→30mは30m→50mと区別され、70mを1行選ぶと、70mが2行の70m(720)は表示されない。
- 選んだ行ごとに、1エンドの矢数、矢の総数、的を、任意に加えたり外したりできる。矢の総数は、その行の総エンド数×1エンドの矢数である(実際に射った矢の数ではない)。的は一覧から選ぶ。加えた項目も含めて一致するラウンドだけが表示され、外した項目は問わない。
- 行を1つも選ばないときは、距離の構成での絞り込みなしである。行を選ぶと、行が0件のラウンド、距離なしの行を持つラウンドは表示されない。無効にした行は構成に含まれない。
- 行の距離、1エンドの矢数、矢の総数は、1以上の整数で指定する。距離は100以下、1エンドの矢数は12以下である。範囲外・整数でない値は不正であることが分かり、不正な条件で絞った結果は表示されない。
- 開始日が終了日より後、下限が上限より大きい、点数として不正な値(負の数、整数でない値)の指定は、不正であることが分かり、不正な条件で絞った結果は表示されない。
- 並べ替えと絞り込みは、同じ欄で操作し、その欄を折りたためる。折りたたんでいる間は選んだ条件を表示しないが、並べ替えと絞り込みは適用され続ける。初めて開いたときは開いている。
- ソートと絞り込みを同時に選ぶと、一致するラウンドだけが選んだ並びで表示される。条件によらず、サーバーで完了と記録されたラウンドだけが表示され、端末の入力中のラウンドと削除済みのラウンドは表示されない。
- 条件を変更すると、表示中のラウンドはスケルトンに置き換わり、先頭から取得し直す。取得中・取得失敗・オフラインの表示は条件を選んでいない場合と同じで、この間ラウンドは表示されない。条件の欄は取得中も表示される。履歴のラウンドを削除すると、条件に一致する表示から消える。
- ソートと絞り込みの条件を、まとめて既定(実施日の新しい順・絞り込みなし。期間・得点の範囲・距離の構成も指定なし)に戻す操作が、その欄の中にある。
- 条件の変更は履歴の取得を起こすが、同期の契機にならず、ホームの表示・入力の開始・再開に影響しない。

### ページ送り

合計点: 履歴で使う合計点は、各射の行を転送せずに、履歴全体に対する並べ替え・比較に使える形で得られる。合計点の規則(無効でない距離の無効でない矢の得点の和、矢がなければ0)は現行の表示と同じである(#386)。

- 履歴は、完了したラウンドを一定件数ずつ表示する。開いたとき、全件を取得しない。続きがあるときは、続きを表示できる。続きがなく、表示するラウンドが1件以上のときは、末尾に「該当するラウンドは以上です」が表示される。表示するラウンドが0件のときは、これは表示されない。
- 並べ替えと絞り込みは、表示済みの分だけでなく、履歴の全ラウンドに対して適用される。全ページを連結した並びは、履歴全体を同じ条件で並べた並びと一致し、同値のラウンドは現行の規則(実施日の新しい順、作成の新しい順、IDの順)で並ぶ。得点の並びも履歴全体で成立する。
- 同じラウンドは、複数のページに重複して表示されず、ページの境界で抜けない。他の端末での完了・削除でページの境界がずれても、重複して表示されない。ただし、読み進める間に、他の端末で続きの起点のラウンドの実施日または合計点が変わったときは、次のページで行が抜けることがある。履歴を開き直すと正しく並ぶ。
- 端末の入力中のラウンドと、この端末で削除したラウンド(サーバーへの反映前を含む)は、削除した時点から、どのページにも表示されない。除外によって1ページの表示件数が減ってもよい(各ページは最大でその件数)。全件が除外されたページがあっても、続きがある限り「該当するラウンドがありません」は表示されず、続きを表示できる。
- 続きの取得中は、続きの取得中であることが分かる。失敗またはオフラインのときは、表示済みのラウンドを残したまま、失敗またはオフラインが分かり、続きの取得を再試行できる。
- 履歴の取得は、画面に表示している情報(名前・実施日・合計点)と、詳細へ移動するためのラウンドの識別情報、続きの有無だけを返す。種別・弓種・作成時刻、各距離・各射の点、総件数など、画面に出さない情報は返さない。

### 履歴へ戻ったとき

- 戻る操作(詳細の戻る、ブラウザの戻る・進む)で履歴に戻ったときは、離れる前の表示(表示済みの内容とスクロール位置)に戻り、取得し直さない。
- 戻ったときの表示は、別の利用者には使われない。条件を変更したときは先頭から取得し直す。この端末で削除したラウンドは表示されない。
- 履歴の項目から開くと、最新の内容を取得する。
- 再読み込みなど、上記以外の開き方での扱いは、要件で決めず、設計で定める。設計は、「履歴の項目から開くと、最新の内容を取得する」との整合を確かめる。

### 条件の保持

- 選んだ条件と絞り込みの開閉は、再読み込みしても、ラウンドの詳細を開いて履歴へ戻っても保たれる。
- 条件と開閉はタブごとに保たれ、別のタブは初めて開いたときの状態から始まる。
- 別の利用者は、条件と開閉が既定の状態で始まる。

### ほかの画面へ進む

- ホームの新規作成ボタン(＋)を押すと、ラウンド作成画面へ移動する。＋はホームだけにあり、履歴・詳細・作成画面にはない。
- ホームの入力中のカードを押すと、そのラウンドの詳細画面へ移動する。戻るリンクはホームへ戻る。
- 履歴のカードを押すと、そのラウンドの詳細画面へ移動する。戻るリンクは履歴へ戻る(遷移元はrounds/detailで扱う)。
- カードのメニューからの削除と確認は、ホームと履歴で同じである(rounds/deleteで扱う)。

### ホームが取得に依存しないこと

- ホームの表示、入力の開始(＋から作成)、入力の再開(入力中のカードから詳細を開く)は、履歴の取得を起動せず、その完了も同期の取得の完了も待たない。
- 履歴の取得と同期の取得が失敗・無応答・オフラインでも、ホームは端末の記録の入力中を表示し、カードから入力を再開でき、＋からラウンドを開始できる。
- 履歴の取得は、履歴を開いたときに初めて行う。ドロワーを開く操作と項目の表示(先読みを含む)は、履歴の取得を起動しない。

### オフラインのとき

- オンラインで開いた後は、オフラインで開き直しても、ホームに入力中のラウンドが名前・実施日・合計点で表示される。
- オフラインでも、入力中のラウンドのカードからラウンド詳細を開ける。
- オフラインで作成して点数を記録した送信前のラウンドは、記録した点数を含む合計点でホームに表示される。
- オフラインで入力を完了するとホームへ移り、完了したラウンドはホームに表示されず、履歴にも出ない。
- 端末に別のユーザーの入力中のラウンドがあっても、別のユーザーでサインインしてオフラインで開くと、そのラウンドは表示されない。
- オフラインで履歴を開くと、履歴の中に「ネットワークに接続されていません」が表示され、ラウンドは表示されない。

### オンラインに戻ったとき、他の端末で変更したとき

- オフラインで点数を記録したラウンドは、オンラインに戻った直後の送信前に開いても、ホームに1件だけ、記録した点数を含む合計点で表示される。
- オフラインで入力を完了したラウンドは、同期でサーバーに完了が反映され、その後に履歴を開いて取得すると、履歴に1件だけ表示される。それまではホームにも履歴にも表示されない。
- 履歴を開いたときの取得で、他の端末で完了したラウンドが現れる。
- 他の端末の入力中のラウンドへの点数、完了、削除は、ホームには起動・通信の復帰・画面が見える状態になったときの同期の後に反映される。ホームや履歴を開いたことは同期の契機に加えず、開いている間の定期の更新もない。
- 入力中のラウンドを完了または削除すると、ホームから消える。

### 見出し

- どの画面にも、見出し「ラウンド一覧」「ラウンドを作成」は表示されない。

### 将来への制約(今回は実装しない)

- ホームの入力中は、並べ替えと絞り込みの対象外である。
- ビューが増えても、ホームと履歴の切替は変わらない。＋は絞り込みの取っ手と重ならない。

## 対象外

- 距離ごとの点数の表示、並べ替え、得点の範囲の距離単位での絞り込みは、別作業で扱う。
- 1ページの件数の数値と、続きを表示する操作の形は、設計で決める。
- #386の対象のうち、ホームの一覧(/rounds)の合計点は、今回の対象外である。別作業の候補として扱うか否かは、決まっていない。
- アプリの起動をまたぐ前回のビューの復元と、入力中の件数バッジは扱わない。
- ホームと履歴の切替の項目と、未認証で開いたときのサインイン画面への移動は、app/navigationで扱う。
- ラウンドの削除のメニューと確認は、rounds/deleteで扱う。
- 戻るリンクと遷移元は、rounds/detailで扱う。
- 入力中のラウンドが無いときのオフラインの表示と、その表示からのオンライン復帰は、app/offline-pwaで扱う。
- 点数やラウンドの送信と同期は、rounds/syncで扱う。
