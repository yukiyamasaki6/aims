# rounds/history

## 目的

利用者が、入力中のラウンドと過去のラウンドを一覧から見つけて開けるようにする。

## 要求

### 一覧を開く

- 認証済みで開くと、各ラウンドの名前・実施日・合計点が表示される。
- 入力中のラウンドがあるときは、入力中のラウンドが実施日に関わらず先頭の「入力中」の見出しの下にまとめて表示され、「過去履歴」の見出しの下には表示されない。
- 入力中のラウンドがあるときは、入力中でないラウンドが「入力中」の後の「過去履歴」の見出しの下に表示される。
- 入力中のラウンドと入力中でないラウンドは、それぞれ実施日の新しい順に表示される。
- 入力中のラウンドが無いときは、「入力中」と「過去履歴」の見出しは表示されず、ラウンドが見出しなしで表示される。
- 開くときにセッションの更新が別の書き手の更新と重なっても、「サインインが必要です。」は表示されず、ラウンドが表示される。

### ほかの画面へ進む

- 新規作成ボタンを押すと、ラウンド作成画面へ移動する。
- ラウンドのカードを押すと、そのラウンドの詳細画面へ移動する。

### オフラインのとき

- オンラインで一覧を表示した後は、オフラインで開き直しても、入力中のラウンドが名前・実施日・合計点で表示され、「過去履歴」の見出しの下に「ネットワークに接続されていません」が表示される。
- オフラインでも、入力中のラウンドのカードからラウンド詳細を開ける。
- オフラインで作成して点数を記録した送信前のラウンドは、記録した点数を含む合計点で表示される。
- オフラインで入力を完了して一覧へ移ると、完了したラウンドは表示されず、他の入力中のラウンドと「ネットワークに接続されていません」が表示される。
- 端末に別のユーザーの入力中のラウンドがあっても、別のユーザーでサインインしてオフラインで開くと、そのラウンドは表示されない。

### オンラインに戻ったとき、他の端末で変更したとき

- オフラインの一覧でオンラインに戻ると、入力中でないラウンドも表示され、「ネットワークに接続されていません」が表示されなくなり、同じラウンドは2件表示されない。
- オフラインで点数を記録したラウンドは、オンラインに戻った直後の送信前に開いても、1件だけ、記録した点数を含む合計点で表示される。
- オフラインで入力を完了したラウンドは、オンラインに戻ると、入力中のラウンドの並びでなく、それ以外のラウンドの並びに1件だけ表示される。
- 他の端末で入力中のラウンドに点数を記録した後に開くと、他の端末の点数を含む合計点で表示される。
- 他の端末で入力中のラウンドを削除した後に開くと、取得の完了後、そのラウンドは表示されない。
- 他の端末で入力中のラウンドを完了にした後に開くと、取得の完了後、そのラウンドは入力中のラウンドの並びに表示されず、それ以外のラウンドの並びに1件だけ表示される。

### 取得を待つ間、取得できないとき

- 通信できないときは、「読み込めませんでした。」と再試行ボタンが表示され、見出しと新規作成ボタンは表示される。
- 取得がエラーになるときは、エラーメッセージが表示され、見出しと新規作成ボタンは表示される。
- オンラインのまま通信に失敗しても、入力中のラウンドは表示され、「過去履歴」の見出しの下に「読み込めませんでした。」と再試行ボタンが表示される。
- オンラインのまま一覧の取得が応答しないときは、通信の開始から1秒以内に入力中のラウンドが表示される。
- オンラインのまま一覧の取得が応答しないで入力中のラウンドを表示した後に、取得が完了すると、各ラウンドが1件ずつ表示される。
- 他のタブが端末の保存の読み書きを続けているときは、開いてから10秒後に「読み込めませんでした。」と再試行ボタンが表示される。

## 対象外

- 利用者が並び順を変える操作、絞り込み、ページ送りは扱わない。
- オフラインでの、入力中でないラウンドの表示は扱わない。
- ラウンドの削除のメニューと確認は、rounds/deleteで扱う。
- 入力中のラウンドが無いときのオフラインの表示と、その表示からのオンライン復帰は、app/offline-pwaで扱う。
- 点数やラウンドの送信と同期は、rounds/syncで扱う。
- 未認証で開いたときのサインイン画面への移動は、app/navigationで扱う。
