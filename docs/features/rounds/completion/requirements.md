# rounds/completion

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| completion-01 | 距離が1つあるラウンドを開始した | /rounds/[id]を開く | 入力を完了するボタンが画面の最下部に表示される |
| completion-02 | 距離が複数あり、スクロールが必要なラウンド詳細画面 | 画面を最下部までスクロールする | 入力を完了するボタンが最下部に表示されたままで、内容が隠れない |
| completion-03 | 全てのエンドが矢数に達したラウンド詳細画面 | 入力を完了するボタンをクリックする | 確認なしで完了になる<br>ラウンド一覧へ移る<br>ブラウザの戻るで戻ると、ボタンが表示されない詳細が表示される |
| completion-04 | 矢数に達していないエンドがあるラウンド詳細画面 | 入力を完了するボタンをクリックし、確認ダイアログで完了するを選ぶ | 完了になる<br>ラウンド一覧へ移る |
| completion-05 | 矢数に達していないエンドがあるラウンド詳細画面 | 入力を完了するボタンをクリックし、確認ダイアログでキャンセルする | 入力中のままで、ボタンが表示され続ける<br>ラウンド詳細画面に留まる |
| completion-06 | 完了にして一覧へ戻った後に開いたラウンド詳細画面 | エンドの空白をクリックして点数を記録する | 入力を完了するボタンが再び表示される<br>再読み込みしても表示される |
| completion-07 | 完了にして一覧へ戻った後に開いたラウンド詳細画面 | 距離を追加する | 入力を完了するボタンが再び表示される |
| completion-08 | 完了にして一覧へ戻った後に開いたラウンド詳細画面 | ラウンドの名前を変える | 入力を完了するボタンは表示されない |
| completion-09 | 完了にして一覧へ戻った後に開いた、記録済みの矢があるラウンド詳細画面 | その矢の玉をクリックし、同じ点数のボタンをクリックする | 入力を完了するボタンは表示されない |
| completion-10 | 入力中のラウンド詳細画面でモバイル | テンキーを展開する | 入力を完了するボタンの位置と見た目が変わらず、テンキーがボタンの上に重なって覆う |
| completion-11 | 距離がないラウンド詳細画面 | 入力を完了するボタンをクリックする | 記録がない旨の確認ダイアログが表示される |
| completion-12 | オフラインのラウンド詳細画面 | 入力を完了するボタンをクリックし、確認する | ラウンド一覧へ移る |
