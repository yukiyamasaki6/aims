# rounds/completion

## 目的

利用者が、記録を終えたラウンドを完了にし、完了の後に記録を変えたときは入力中に戻るようにする。

## 要求

### 入力を完了する

- 入力中のラウンドを開くと、入力を完了するボタンが表示される。
- 全てのエンドが矢数に達したラウンドで入力を完了するボタンを押すと、確認なしで完了になり、ラウンド一覧へ移る。
- 完了にした後、ブラウザの戻るで詳細へ戻っても、再読み込みしても、入力を完了するボタンは表示されない。

### 確認して完了する

- 矢数に達していないエンドがあるラウンドで入力を完了するボタンを押すと、確認ダイアログが表示される。
- 矢数に達していないエンドがあるラウンドの確認ダイアログで完了するを選ぶと、完了になり、ラウンド一覧へ移る。
- 確認ダイアログでキャンセルすると、入力中のままラウンドの詳細に留まり、入力を完了するボタンが表示され続ける。
- 距離がないラウンドで入力を完了するボタンを押すと、記録がない旨の確認ダイアログが表示される。

### 完了したラウンドを編集したとき

- 完了のラウンドでエンドの空白を押して点数を記録すると、入力中に戻り、入力を完了するボタンが再び表示され、再読み込みしても表示される。
- 完了のラウンドで距離を追加すると、入力中に戻り、入力を完了するボタンが再び表示され、再読み込みしても表示される。
- 完了のラウンドでラウンドの名前を変えても、完了のままで、入力を完了するボタンは表示されない。
- 完了のラウンドで記録済みの矢に同じ点数を書いても、完了のままで、入力を完了するボタンは表示されない。

### 長いスコアカードをスクロールするとき

- テンキーを格納しているときは、1画面に収まらない入力中のラウンドを最後までスクロールしても、入力を完了するボタンが隠れずに見える。
- 1画面に収まらない入力中のラウンドを最後までスクロールすると、スコアカードの最後まで、入力を完了するボタンに隠れずに見える。

### オフラインのとき

- オフラインでも、入力を完了するボタンを押して確認すると完了になり、ラウンド一覧へ移る。

## 対象外

- 完了のラウンドを開いたときの表示(仮の矢、テンキー、ラウンド編集ダイアログ)は、rounds/detailで扱う。
- 一覧での入力中と完了のラウンドの分け方は、rounds/historyで扱う。
- 完了と入力中への変更の送信と同期は、rounds/syncで扱う。
- 他の端末で完了にしたことを知らない端末で編集したときに、入力中へ戻すことは扱わない。
