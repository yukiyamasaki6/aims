# ラウンド名のヘッダー編集とドロップダウン入力のテスト設計

## 基準と範囲

基準は[設定の要件](requirements.md)と[設計](design.md)だけである。
対象は、ヘッダーのラウンド名のその場の編集、ラウンド編集ダイアログの項目の並びと種別・弓種のドロップダウン、距離編集ダイアログのMarked/Unmarkedのドロップダウン、それらが積む操作である。
検証の規則(距離・射数/エンド・エンド数の範囲、矢に収まらない変更)、同期、距離の追加・削除、的選択は変更対象外であり、既存の下層テストを再利用する。
画面の配置とデザイン(ヘッダーの収まり、横並び)は、`agents/testing.md`によりE2Eの期待値にせず、手動で確かめる。
優先順位は、名前の意図しない保存・消失の防止、キーボードと支援技術での操作、既存の保存結果の維持の順とする。

## テスト層と観測

| 層 | 保証する内容 | 観測方法 |
| --- | --- | --- |
| 単体（Vitest） | ラウンド編集の検証(`validateRoundConfig`)が実施日・種別だけを検証し、名前を検証しないこと | 51文字の名前を含む設定を与えても、名前の誤りが返らないこと(名前の誤りの種類を持たないこと)を確かめる。 |
| コンポーネント（Vitest） | 名前の表示・編集・確定・取り消し・文字数の制限、ダイアログの項目とドロップダウン、積む操作 | `IntlTestProvider`で描き、role・名前・文言で操作し、追記された操作の内容で確かめる。 |
| E2E（Playwright） | 名前の編集と、ドロップダウンでの種別・弓種・Marked/Unmarkedの変更が、保持される | 既存の`setup.spec.ts`などの主要経路の操作を新しい入力へ更新する。 |
| 手動表示確認 | ヘッダーの収まり、横並び | ビルド済みの`pnpm preview`。 |

## コンポーネントのケース

正常系から異常系の順にする。1テストは1つの前提と操作の結果に限る。

| テスト名の案 | 前提と操作 | 期待結果 |
| --- | --- | --- |
| ヘッダーに名前を表示し、概要には名前を含めない | 名前のあるラウンドを描く。 | ヘッダーに名前があり、概要の文字列に名前がなく、実施日・種別・弓種だけが「 / 」で並ぶ。 |
| 名前が空のときはプレースホルダーを出して押せる | 名前が空のラウンドを描く。 | プレースホルダー(「ラウンド名」)のボタンがあり、押すと入力欄になる。 |
| 名前のボタンの名前は「ラウンド名を編集」で始まり、名前のあるときは「ラウンド名を編集: <名前>」である | 名前のあるラウンドと空のラウンドを描く。 | role=buttonの名前が、空のときは「ラウンド名を編集」、名前のあるときは「ラウンド名を編集: <名前>」である。入力欄に変わると、名前「ラウンド名」の入力欄だけがあり、ボタンはない。 |
| 名前を押すと入力欄に変わり、フォーカスが入って、文字が全て選択される | 名前のあるラウンドと空のラウンドの名前を個別に押す。 | 現在の名前を値に持つ入力欄(名前「ラウンド名」)にフォーカスがあり、表示のボタンはない。名前のあるときは、入力欄の選択範囲が値の全体(先頭から末尾)で、空のときは選択範囲が空である。 |
| Enterで名前を確定すると、変えた名前の操作を積み、表示に戻る | 名前を変えてEnterを押す。 | 名前だけを変える`round.updated`が1件積まれ、表示が新しい名前になり、フォーカスが名前のボタンへ移る。 |
| 入力欄の外を操作すると名前を確定する | 名前を変えて、別の要素へフォーカスを移す。 | 操作が1件積まれ、表示が新しい名前になる。フォーカスは移した先に残る。 |
| 変えていない名前は確定しても操作を積まない | 名前を変えずにEnterを押す。 | 操作が積まれず、表示に戻る。 |
| 入力欄は50文字までで、51文字目以降は入力できない | 名前を編集中に、60文字を入力し、貼り付けでも60文字を与える。 | 入力欄の値が50文字になり、確定すると50文字の名前の操作が積まれる(50文字の名前は、そのまま確定できる)。 |
| 変換中のEnterでは確定しない | 変換中(`isComposing`)のEnterを送る。 | 入力欄のままで、操作が積まれない。 |
| Escで取り消すと編集前の名前のままで、その後のblurでも確定しない | 名前を変えてEscを押し、フォーカスを外す。 | 操作が積まれず、表示は編集前の名前で、フォーカスが名前のボタンにある。 |
| 編集中に外の値が変わっても、入力は書き換わらない | 編集中に、他の項目(実施日)を変える外の更新を与える。 | 入力欄の文字が変わらず、確定の操作は名前だけを含む。 |
| ラウンド編集ダイアログに名前の欄がなく、実施日、種別・弓種の欄がある | 概要を押す。 | 名前の入力欄がなく、実施日の入力欄と、名前「種別」「弓種」のドロップダウンがある。 |
| 種別・弓種は選択肢から1つ選び、「指定なし」がない | 種別のドロップダウンを開く。 | 選択肢の名前がアウトドア・インドア・フィールドで、「指定なし」がない。弓種も同様に3つの選択肢だけである。 |
| 種別と弓種を変えて保存すると、その項目だけを変える操作を積む | 種別と弓種を選び直して保存する。 | 変えた2項目だけを持つ`round.updated`が積まれ、ダイアログが閉じる。 |
| 何も変えずに保存しても操作を積まず、ダイアログを閉じる | 開いて保存する。 | 操作が積まれず、閉じる。 |
| Unmarkedの距離が残るとき、フィールド以外への変更はエラーになる | Unmarkedの距離があるラウンドで、種別をフィールド以外にして保存する。 | 種別のエラーの文言が表示され、種別の欄から参照され(`aria-describedby`)、保存されず、ダイアログが開いたままである。 |
| 距離編集は、フィールドのときだけMarked/Unmarkedのドロップダウンを持つ | フィールドとフィールド以外のラウンドの距離編集を個別に開く。 | フィールドには名前「Marked / Unmarked」のドロップダウンがあり、選択肢がMarkedとUnmarkedである。フィールド以外にはない。 |
| Marked/Unmarkedを選び直して保存すると、`is_marked`を変える操作を積む | フィールドの距離でUnmarkedを選んで保存する。 | `is_marked`だけを変える`distance.updated`が積まれる。 |

名前の編集と保存の規則(起点との差、変えた項目がなければ操作を積まない)は、既存の`buildRoundUpdatedOperation`のテストを再利用し、重複して追加しない。
ヘッダーの高さ・横並び・エラーの位置は、コンポーネントテストで期待値にしない。

## 取得中・見つからない・オフライン・取得エラーのヘッダー

| テスト名の案 | 前提と操作 | 期待結果 |
| --- | --- | --- |
| 取得中・見つからない・オフライン・エラーではヘッダーに名前を出さない | 各状態で詳細を描く。 | 「戻る」リンクはあり、名前のボタン・入力欄がない。表示になると名前が出る。 |

## E2Eのケース

既存の主要経路の操作を、新しい入力へ更新する。新しい経路は、名前の編集の1つだけを足す。

- ラウンド詳細で、ヘッダーの名前を押して入力欄に変え、新しい名前をEnterで確定し、再読み込みしても新しい名前が表示される。
- 既存のラウンド設定の変更(`setup.spec.ts`)は、ドロップダウンで種別・弓種を選び直す操作に更新する。
- 既存のMarked/Unmarkedの変更は、ドロップダウンで選ぶ操作に更新する。
- ボタンの識別子(`round-config-name`、`round-config-format-*`、`round-config-bow-type-*`、`distance-config-marked-*`・`distance-config-unmarked-*`)に依る既存のテストと、概要の文字列に名前を含む期待値を更新する。更新対象は、`round-config-panel.test.tsx`、`distance-edit-fields.test.tsx`、`scorecard-client.test.tsx`、`domain/round-config.test.ts`(名前の`tooLong`に関するケースを削除)と、`setup.spec.ts`、`detail.spec.ts`、`preset.spec.ts`、`sync.spec.ts`、`offline-pwa.spec.ts`、`settings.spec.ts`のうち該当する操作である。

## 手動での表示確認

ビルドを含む`pnpm preview`(port 3000)で、既存プロセスは停止しない。幅360・375・768で確認する。

| 確認内容 |
| --- |
| ヘッダーの名前が、「戻る」とプリセット保存・ラウンドのメニューの間に収まり、長い名前は末尾が省略され、ヘッダーの高さ(45px)が変わらない。 |
| 名前が空のとき、プレースホルダー「ラウンド名」が薄い文字で、押せると分かる。 |
| 名前を押して編集に入ると、入力欄の文字が全て選択された状態になり、見た目が選択を示す。続けて文字を入力すると、選択した文字が置き換わる。名前を押して編集に入っても、文字の大きさと位置と枠の幅が動かない。入力した文字に応じて枠の幅が増減し、空のときはプレースホルダーの幅で、長い名前では最大幅(ヘッダーの残り)で表示は省略、入力欄は内部でスクロールする。幅360でも幅768でも同じである。 |
| 端から最初のアイコンまでの見た目とアイコン同士の見た目が同じ(約10px)で、戻る・名前・プリセット保存・メニューの間が詰まりすぎず離れすぎず、押せる範囲が重ならない。ホーム、点数一覧、詳細、設定パネル内の画面でも同じである。 |
| 名前の文字の大きさが、表示と入力欄で同じ14px(「戻る」と同じ)で、幅によって変わらない。iOSで入力欄にフォーカスしたときに画面が拡大しても、利用者が戻せる(受け入れ済み)。 |
| 名前の編集中、入力欄がヘッダーの中に収まり、幅が狭くても右の操作と重ならず、ヘッダーの高さが変わらない。 |
| ラウンド編集ダイアログが、実施日、種別・弓種(横に2つ)の順で、幅360でも選択肢の表示が欠けない。 |
| 距離編集ダイアログが、フィールドは「Marked/Unmarked・距離」、「射数/エンド・エンド数」、的の順で、フィールド以外は距離が幅いっぱいで、幅360でも項目名と各欄のエラーの文言が欠けない。 |
| ドロップダウンの選択肢の一覧が、ダイアログの手前に出て、画面の高さが低いときも選べる。 |

寸法の値は画面で確認して確定する値であり、調整したら設計の記述も同時に直す。
未実行の項目は成功に含めず、後続の報告で分けて記録する。
