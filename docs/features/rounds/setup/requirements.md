# rounds/setup

## 目的

利用者が、ラウンドの設定と距離の構成を、記録の前にも後にも見直して変えられるようにする。

## 要求

### ラウンドの設定を見て変える

- 開くと、ラウンド名・実施日・種別・弓種が1行で表示される。
- ラウンドの概要を押すと編集ダイアログが開き、変えて保存すると、すぐに反映されてダイアログが閉じ、変えた内容が保持される。
- ラウンド名が51文字以上のときは、保存するとエラーが表示され、保存されない。

### 距離を見て変える

- 開くと、各距離の距離・的・本数・エンド数が表示される。
- 距離の概要を押すと編集ダイアログが開き、距離・的・本数・エンド数を変えて保存すると、すぐに反映されてダイアログが閉じ、変えた内容が保持される。
- 種別がフィールドのときは、距離編集でMarked/Unmarkedを切り替えられる。
- 的・本数・エンド数を変えて保存すると、その距離の矢への書き込みは、一つ戻る・一つ進むで戻せなくなる。

### 距離を追加する

- 距離が無いときは規定値で、あるときは最後の距離の内容をコピーして距離が追加され、その距離の編集ダイアログが開く。追加した距離は保持される。
- 距離を追加して削除した後も、距離を追加でき、エラーは表示されず、追加した距離は保持される。

### 的を選ぶ

- 距離編集で的を押すと、ラウンドの種別と弓種に一致するフィルタで的選択ダイアログが開き、一致する的がサイズの大きい順に表示される。
- 的を選ぶと、その的が選ばれ、的選択ダイアログが閉じる。

### 距離を削除する

- 削除すると、その距離が一覧から消え、ダイアログが閉じる。削除は保持される。
- 記録済みの得点がある距離は、確認ダイアログで確認すると削除される。確認のキャンセルと背景のクリックでは削除されない。

### 記録済みの得点がある距離を開いたとき

- 的・本数・エンド数は編集できず、押すと、記録済みの得点があるため変更できないというメッセージが表示される(的は選択ダイアログを開かない)。

### ダイアログを閉じる

- ラウンド編集と距離編集は、背景を押すと、変更を破棄して閉じる。
- 的選択は、背景を押すと的選択だけが閉じ、距離編集は開いたままになる。

### オフラインのとき、的の一覧を取得中か取得できないとき

- オフラインでも、的を端末に保存済みなら、作成が未確定のラウンドに追加した距離に的のサイズと図が表示され、的選択ダイアログに的の一覧が表示される。
- 作成が未確定で距離があるラウンドで、的の一覧の取得が完了していないときは、ラウンドの内容の代わりに読み込み中が表示され、取得が完了すると、距離の行に的のサイズと図、テンキーに的の点数のキーが表示される。
- 的の一覧を取得できないときは、距離の行と距離編集の的のボタンに「的データを取得できません」が表示される。

### 他の端末の変更が届いたとき

- ラウンド編集中や距離編集中に他の端末の変更が届いても、変更中の内容は残り、保存すると、変えた項目と他の端末で変えられた項目の両方が保たれる。

## 対象外

- 点数の記録と直しは、rounds/score-entryで扱う。
- 書き込みの送信と再送、再読み込み後の復元、他の端末との衝突の規則は、rounds/syncで扱う。
- ラウンド・距離・的の取得と、ラウンド詳細の表示は、rounds/detailで扱う。
- 構成をプリセットとして保存することは、rounds/presetで扱う。
