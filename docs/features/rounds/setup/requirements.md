# rounds/setup

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| setup-01 | ラウンド詳細画面で認証済み、ラウンド名が入力されている | /rounds/[id]を開く | ラウンド名・実施日・種別・弓種が1行で表示される |
| setup-02 | ラウンド詳細画面で距離が1件以上ある | /rounds/[id]を開く | 各距離の距離・的・本数・エンド数が表示される |
| setup-03 | ラウンド詳細画面 | ラウンド概要をクリックする | ラウンド編集ダイアログが開く |
| setup-04 | ラウンド編集ダイアログ | ラウンド名・実施日・種別・弓種を変更して保存ボタンをクリックする | 編集内容が即座に反映され、ダイアログが閉じられる<br>編集内容が保持される |
| setup-05 | ラウンド詳細画面で距離が1件もない | 「距離を追加」ボタンをクリックする | 規定値で距離が追加され、距離編集ダイアログが開く<br>追加した距離が保持される |
| setup-06 | ラウンド詳細画面で距離が1件以上ある | 「距離を追加」ボタンをクリックする | 直前の距離の内容をコピーした距離が追加され、距離編集ダイアログが開く<br>追加した距離が保持される |
| setup-07 | ラウンド詳細画面で距離が1件以上ある | 距離概要をクリックする | 距離編集ダイアログが開く |
| setup-08 | 距離編集ダイアログ | 距離・的・本数・エンド数を変更して保存ボタンをクリックする | 編集内容が即座に反映され、ダイアログが閉じられる<br>編集内容が保持される |
| setup-09 | 距離編集ダイアログで取り消し・やり直しの履歴があり、記録済みの得点がない | 的・本数・エンド数を変更して保存ボタンをクリックする | 編集内容が即座に反映され、ダイアログが閉じられる<br>その距離の矢への書き込みを、一つ戻る・一つ進むで戻せなくなる |
| setup-10 | ラウンド詳細画面で種別がフィールド、距離が1件以上ある | 距離概要をクリックする | 距離編集ダイアログにMarked/Unmarkedの切り替えが表示される |
| setup-11 | 距離編集ダイアログ | 的をクリックする | ラウンド設定に一致するフィルタが選ばれた状態で的選択ダイアログが開く<br>フィルタに一致する的だけが、サイズの大きい順に表示される |
| setup-13 | 的選択ダイアログ | 的をクリックする | その的が選択され、的選択ダイアログが閉じられる |
| setup-14 | 距離編集ダイアログ | 削除ボタンをクリックする | その距離が一覧から削除され、ダイアログが閉じられる<br>距離の削除が保持される |
| setup-15 | 距離編集ダイアログで距離に記録済みの得点がある | 削除ボタンをクリックする | 距離削除確認ダイアログが開く |
| setup-16 | 距離削除確認ダイアログ | 確認ボタンをクリックする | その距離が一覧から削除され、ダイアログが閉じられる<br>距離の削除が保持される |
| setup-18 | ラウンド詳細画面で距離に記録済みの得点がある | 距離概要をクリックする | 距離編集ダイアログの的・本数・エンド数が編集できない |
| setup-19 | ラウンド編集ダイアログで内容を変更している | 背景をクリックする | 変更が破棄され、ダイアログが閉じられる |
| setup-20 | 距離編集ダイアログで内容を変更している | 背景をクリックする | 変更が破棄され、ダイアログが閉じられる |
| setup-21 | 的選択ダイアログ | 背景をクリックする | 的選択ダイアログが閉じられる<br>距離編集ダイアログは開いたままである |
| setup-22 | 距離削除確認ダイアログ | キャンセルボタンをクリックする | ダイアログが閉じられる<br>距離は削除されない |
| setup-23 | 距離削除確認ダイアログ | 背景をクリックする | ダイアログが閉じられる<br>距離は削除されない |
| setup-24 | ラウンド編集ダイアログでラウンド名が51文字以上 | 保存ボタンをクリックする | エラーメッセージが表示され、保存されない |
| setup-25 | オフラインで的を端末に保存済み、作成が未確定で距離がないラウンド | 「距離を追加」ボタンをクリックする | 追加した距離に的のサイズと図が表示される |
| setup-26 | オフラインで的を端末に保存済み、作成が未確定で距離がないラウンドの距離編集ダイアログ | 的をクリックする | 的選択ダイアログに的の一覧が表示される |
| setup-27 | 作成が未確定で距離があるラウンドで、的の一覧の取得が完了していない | /rounds/[id]を開く | ラウンドの内容が表示されない<br>読み込み中と表示される |
| setup-32 | 作成が未確定で距離があるラウンドで、的の一覧の取得が完了せず、読み込み中と表示されている | 的の一覧の取得が完了する | 距離の行に的のサイズと図が表示される<br>テンキーに的の点数ボタンが表示される |
| setup-29 | ラウンド詳細画面で距離を追加して削除した後 | 「距離を追加」ボタンをクリックする | 距離が追加され、エラーメッセージが表示されない<br>追加した距離が保持される |
| setup-30 | ラウンド編集ダイアログで内容を変更している | 他の端末の変更が取得で届く | 変更中の内容が残る<br>保存すると、変更した項目と、他の端末で変更された項目の両方が保たれる |
| setup-31 | 距離編集ダイアログで内容を変更している | 他の端末の変更が取得で届く | 変更中の内容が残る<br>保存すると、変更した項目と、他の端末で変更された項目の両方が保たれる |
