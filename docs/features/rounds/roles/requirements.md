# rounds/roles

## 目的

ラウンドの参加者を、実際に射つ人(射つ人)と、試合や練習で申告された点数を記録する人(代理の人)に分ける。
代理の人は記録に要る操作をすべて行え、ラウンドの削除と代理の人の追加は射つ人だけに限る。

## 要求

### ラウンドの役割

- ラウンドの参加者の役割は、射つ人と代理の人の2つである。読むだけの役割はない。
- ラウンドを作った人は、そのラウンドの射つ人になる。
- ラウンドには、射つ人が常に1人以上いる。
- 射つ人は、必ずそのラウンドの番号に結び付く(rounds/shooters)。番号のない射つ人はいない。

### 代理の人ができること

- 代理の人は、点数の記録・修正、距離と名前などの設定の変更、入力の完了と入力中への戻し、矢の射手の付け替え、利用者に紐づかない射手の追加ができる(rounds/shooters)。
- 代理の人は、ラウンドを削除できず、代理の人を加えられない。

### ラウンドを削除する

- 射つ人が1人のラウンドは、その射つ人が削除できる。
- ほかに射つ人がいるラウンドは、射つ人でも削除できない。
- 射つ人は、ほかの射つ人をラウンドから外せない。

### アカウントを削除したとき

- 射つ人がいなくなるラウンドは、代理の人が残っていても、距離・矢・それらの変更履歴とともに消える(auth/delete-account)。
- 2人の射つ人が同時にアカウントを削除しても、射つ人のいないラウンドは残らない。

## 対象外

- 射つ人・代理の人を加える操作と、加えられる人の同意。
- ラウンドから外れる操作と、外れたときの記録の扱い。
- 代理記録の任せ方と、その画面。
- 読むだけの人の扱い(ラウンドごとの閲覧者を設けるか、チームの所属で見せるか)。
- 複数人で1つのラウンドを射つ共同型の画面。
- チーム。
