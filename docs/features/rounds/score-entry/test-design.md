# 矢のマス目形式(画面・単体)のテスト設計

## 基準と範囲

基準は[score-entryの要件](requirements.md)・[設計](design.md)、[detailの要件](../detail/requirements.md)・[設計](../detail/design.md)、[completionの要件](../completion/requirements.md)・[設計](../completion/design.md)、[setupの設計](../setup/design.md)(構成に収まらない判定)だけである。
実装やテストコードの内容から期待値を導かない。
同期とDBは[syncのテスト設計](../sync/test-design.md)で扱う。
画面の配置とデザイン(寸法、段の数の見え方、輪の色、玉の色)は`agents/testing.md`によりE2Eの期待値にせず、手動で確かめる。段の数の決め方の計算は単体で確かめる。

優先順位は、記録の取り違え・上書きの防止(マスと射順の対応)、前から順に書ける遷移、戻る・進むの正しさ、位置が動かないことの順とする。
壊れた場合の影響が大きいのは、別のマスへの書き込みである。

## テスト層と観測

| 層 | 保証する内容 | 観測方法 |
| --- | --- | --- |
| 単体(Vitest、domain) | マスの同一性、指すマスの遷移、取り消しの列、矢の操作の組み立て、構成に収まる判定、完了の判定 | 純粋関数の入力と戻り値。 |
| コンポーネント(Vitest、ui) | マスの固定表示、空のマスの読み上げ、押下と指す輪、テンキーの有効条件、書いた後の遷移、動きの廃止、スクロール追従 | 公開UIのrole・名前・状態。`IntlTestProvider`で包み、文言は翻訳の関数で得る。 |
| E2E(Playwright) | 書く・直す・消す・戻す・進むの主要経路が、実DBへ保存され再読み込みで同じマスに表示される | 実ブラウザ・実DB。利用者とデータはテストごとに作る。 |
| 手動表示確認 | 空のマスの輪、玉と輪の見え方、折り返しの段、点数による並べ替えがないこと | ビルド済みの`pnpm preview`。 |

同じ規則の組合せは下層で確かめ、E2Eは接続の確認に必要なケースだけを選ぶ。
E2Eの直接の検証対象にしない: テンキーの開閉の途中、フォーカス、スクロール位置、段の数。
実DBで作れない状態(取得の失敗など)はコンポーネントで確かめる。
検証データは実際に起こりうる形にする(屋外の12エンド×3射・6エンド×6射など)。マスの範囲の境界は、その値自体が検証対象のため射数/エンドを変えてよい。

## 単体(domain)

ケースは正常系から異常系の順に書く。

| テスト名の案 | 前提と操作 | 期待結果 |
| --- | --- | --- |
| 同じマスの判定は距離・エンド・番号の3つが一致するときだけ真になる | 3つのうち1つずつ違うマスを比べる。 | 1つでも違えば偽である。マスの鍵も同じ区別で一意になる。 |
| マスにある生きている矢だけを返す | 生きている矢、取り消し済みの矢、別のマスの矢を持つ表で検索する。 | 生きている矢だけが見つかり、取り消し済みと別のマスは見つからない。 |
| 最初の空のマスは、距離の並び順、エンドの昇順、マスの番号順で決まる | 先頭の距離の途中のマスと後ろのエンドの空き、次の距離の空きを組み合わせる。 | 距離→エンド→番号の順で最初の空のマスである。後ろのエンドに矢があっても前の空きを返す。 |
| 空のマスが無ければ最初の空のマスは無い | 全てのマスが埋まった表と距離が無い表。 | どちらも指すマスは無い。 |
| 空のマスへ書くと、同じエンドの後ろの最初の空のマスを指す | 空のマスへ書く。後ろに空と埋まったマスが混在する。 | 埋まったマスを飛ばし、後ろの最初の空のマスを指す。書いたマスより前の空は指さない。 |
| 同じエンドの後ろが空でないとき、同じ距離の後ろのエンドの最初の空のマスを指す | エンドの最後のマスへ書く。 | 同じ距離の次のエンド以降の最初の空のマスを指す。満杯のエンドは飛ばす。 |
| 同じ距離の後ろに空のマスが無ければ、次の距離や前方の空きがあっても何も指さない | 最後のエンドの最後のマスへ書く。前のエンドと次の距離に空きを置く。 | 何も指さない。 |
| 記録済みのマスへ書いた後は同じマスを指す | 記録済みのマスへ書く。後ろに空きがある。 | 指すマスは変わらない。 |
| 他の端末で埋まった・空になったマスを指していても、指すマスは動かない | 指しているマスの内容が変わった表で合わせ直す。 | 同じマスのままである。 |
| 範囲外になったマスだけ指さなくなる | エンド数か射数/エンドが減って範囲外になった表で合わせ直す。距離が消えた表も用意する。 | 範囲外か距離が無いときだけ何も指さない。範囲内は空でも埋まっていても保つ。 |
| 同じマスの判定で、指すマスどうしを比べる | 同じ、別、何も指さないものを比べる。 | マスが一致するときだけ同じで、指さないものどうしは同じである。 |
| 戻る・進む: 記録を戻すとそのマスが空になり、指す。進むと同じ点数が戻る | 空のマスへの記録を積んで戻し、進める。 | 戻すと空・そのマスを指す。進めると元の点数・そのマスを指す。 |
| 戻る・進む: 直しを戻すと直す前の点数、クリアを戻すとクリア前の点数だけを書く | 直しとクリアを積んで戻す。 | 点数だけを書き、射手は含めない。そのマスを指す。 |
| 書いた後・クリアした後は進めなくなる | 戻した後に記録かクリアを積む。 | やり直しの列は空になる。 |
| 戻せる書き込みが無いときは戻せない | 空の列。 | 戻る・進むとも対象が無い。 |
| 距離の構成を変えた保存と削除は、その距離のマスの履歴だけを捨てる | 2距離分の履歴から片方を捨てる。 | 他の距離の履歴は残る。 |
| 他の端末が同じマスへ後から書いても、戻した内容が元の点数か空になる操作を組み立てる | 戻す操作を作る。 | 戻す操作は点数または空だけを持ち、マスで指す。 |
| 矢の操作はマス(距離、エンド、番号)で矢を指し、矢のIDを持たない | 記録とクリアの操作を組み立てる。 | 操作にマスの3つが含まれ、矢のID・時刻順のIDは含まれない。 |
| 点数が的にあり、エンドと番号が範囲内のときだけ構成に収まる | 各範囲の境界値(エンド1・エンド数・エンド数+1、番号1・射数/エンド・射数/エンド+1・0)と、的に無い点数。 | 境界の内側は収まり、外側と的に無い点数は収まらない。 |
| 構成に収まるかは、エンドの矢の数でなくマスの範囲で判定する | 距離の全てのマスが埋まった表を、同じ構成で判定する。 | 範囲内なので収まる。数の判定で変わらない。 |
| 総エンド数・射数/エンドを減らすとき、取り消し済みの矢は判定に含めず、範囲外のマスの生きている矢があれば収まらない | 取り消し済みの範囲外の矢と、生きている範囲外の矢。 | 取り消し済みは無視され、生きている範囲外だけが収まらない。 |
| 満杯は全てのマスが埋まった状態で、1マス空けば満杯でない | 全マスと1マス足りない表。 | 完了の確認の有無が分かれる。 |
| 完了のラウンドの編集で入力中へ戻す必要があるかは、マスと点数の比較で決まる | 空のマスへの記録、別の点数への直し、同じ点数の記録、クリア、削除済みの距離への記録。 | 空のマスへの記録・点数の直し・クリアは戻す。同じ点数と削除済みの距離への記録は戻さない。 |
| 既定の距離なしでは最初の空のマスは無い | 距離が無い表。 | 何も指さない。 |

## コンポーネント

| テスト名の案 | 前提と操作 | 期待結果 |
| --- | --- | --- |
| エンドは射数/エンドの個数のマスを番号順に表示し、空のマスも表示する | 一部だけ記録した表を描画する。 | マスは射数/エンドの個数で、番号順に並ぶ。矢の無いマスも表示される。 |
| 記録済みのマスは点数の玉で表示し、空のマスは番号の文字を描かない | 描画して文字を確かめる。 | 玉は点数を表示し、空のマスには数字の文字がない。 |
| 空のマスには「{n}射目、空」の読み上げの名前を付け、記録済みの玉には名前を付けない | role・名前を確かめる。語は翻訳の関数で得る。 | 空のマスの名前は番号と「空」を含み、番号はマスの番号と一致する。玉は名前が無く、中の点数が読まれる。 |
| 全てのマスが押せるボタンで、Tabの移動の対象になる | Tabで進む。 | 空と記録済みの全てのマスに止まる。 |
| 空のマスを押すと、そのマスを指して輪が付き、テンキーが展開される | 格納中に空のマスを押す。 | 指すマスの輪が付き、テンキーが出る。指しているマスを押しても変わらない。 |
| 点数の位置は書いた順や点数で動かない | 順不同の点数を同じエンドの別のマスへ書く。 | 各点数は書いたマスに残り、並べ替わらない。小計は合計になる。 |
| 空のマスへ書くと、そのマスに記録され、後ろの最初の空のマスを指す | マス2を指して書く。マス3が他の利用者に埋められている状態も用意する。 | マス2に記録され、埋まったマスを飛ばして次の空を指す。他のマスは変わらない。 |
| エンドの最後のマスへ書くと、後ろのエンドの最初の空のマスを指す | 最後のマスに書く。 | 次のエンドの最初の空のマスを指す。 |
| 距離の最後の空のマスへ書くと、何も指さずテンキーが格納され、次の距離は指さない。前方の空のマスは押して埋められる | 最後の空に書き、その後前方の空のマスを押して書く。 | 格納され、次の距離のマスは指さない。前方の空は押せて記録される。 |
| 記録済みのマスへ書くと、そのマスの点数だけが変わり、同じマスを指したまま後ろへ移らない | 記録済みのマスを指して別の点数を書く。 | 点数だけが変わり、位置・他のマス・指すマスは変わらない。 |
| 記録済みのマスのクリアで、そのマスだけが空になり指したままである | クリアを押す。 | そのマスだけが空のマスになり、指す輪が残る。 |
| 空のマスを指しているときはクリアを押せず、記録済みのマスを指すと押せる | 空のマスと記録済みのマスを交互に指す。 | 空のときは無効、記録済みのときは有効である。 |
| 画面へ反映される前に続けて押しても、同じマスや範囲外のマスへ重ねて書かない | 続けて点数を押す。 | 書き込みは各マスに1回ずつで、射数/エンドの個数を超えない。 |
| 番号・小計・マスの外を押しても、指すマスとテンキーは変わらない | 各部分を押す。 | 変化しない。 |
| 別の距離のマスを押すと、その距離の的のキーに切り替わる | 的の異なる2距離。 | キーがその距離の的の点数になる。 |
| 戻る: 記録を戻すとそのマスが空になって指し、直し・クリアを戻すとそのマスが指される。進むはやり直したマスを指す | 記録・直し・クリアを戻して進める。 | 各操作後に、対象のマスの内容と指すマスが期待どおり。進む・戻るの有効条件が列に従う。 |
| エンドの最後のマスを記録して次のエンドへ移った直後に戻ると、前のエンドの最後のマスが空になって指される | 最後のマスを記録して戻す。 | 前のエンドのそのマスが空になり、指す。 |
| 戻る・進むを続けて押しても1回だけ戻る | 連続で押す。 | 1回だけ戻り、エラーにならない。 |
| 戻した後に書く・クリアすると、やり直せなくなる | 戻して書く、戻してクリアする。 | 進むが押せない。 |
| 完了のラウンドで空のマスへ書くと入力中へ戻り、記録済みのマスへ同じ点数を書いても戻らない | 完了の表で操作する。 | 前者は完了ボタンが再表示され、後者は完了のまま。 |
| 開いたとき最初の空のマスを指し、完了のラウンドと満杯のラウンドは何も指さない | 入力中(途中のマスが空)、完了、満杯の表。 | 順に、最初の空のマス、指さない・テンキーなし、指さない。 |
| 他の端末の変化で指すマスの内容が変わっても、指すマスは動かず、スクロールで追わない | 指すマスが埋まる・空になる更新を流す。 | 指す輪は同じマスで、スクロールしない。 |
| マスの書き込みや他端末の変化で、動きを付けずにその場で描き替える | 書く・消す・更新を流す。 | 位置を動かす処理が呼ばれず、描き替えだけが起こる(既存の並び直りの動きのテストは撤廃)。 |
| 射数/エンドが1段に収まらないときの段の数と、1段のマスの数は計算の規則どおりで、どの段も同じ列に番号順に並ぶ | 例: 射数/エンド6で1段に4つまで収まる幅。 | 3つずつ2段で、左上から番号順に並ぶ。 |
| 構成の変更で範囲外になったマスは描かず、指していたときは指さなくなる | エンド数か射数/エンドを減らす。 | そのマスは表示されず、指す輪も外れる。 |
| 範囲外の矢が残るときの総エンド数・射数/エンドの変更は、記録済みのスコアが失われる旨のエラーで保存できない | 範囲外のマスの矢がある距離を編集する(setup)。 | 該当の入力の下にエラーが出て、保存しない。範囲内に収まる変更は保存できる。 |
| 指す行が隠れていれば、利用者の操作と配置の変化のときだけスクロールする | 既存のスクロールのケースを、マスの用語で維持する。 | 既存と同じ期待結果。 |

## E2E

| テスト名の案 | 前提と操作 | 期待結果 |
| --- | --- | --- |
| 点数を順不同に書くと、書いたマスに記録され、再読み込みしても同じ位置と小計で表示される | 6エンド×6射のラウンドを開き、マス順に値を書く。再読み込みする。 | 書いた順のまま並び、点数の高い順に並び替わらない。小計は同じである。 |
| 直前に飛ばして空けたマスを押して書くと、そのマスに記録される | マス2を飛ばして書いた後にマス2を押して書く。 | マス2に記録され、他のマスは動かない。再読み込み後も同じ。 |
| 記録済みのマスを直すと点数だけが変わり、再読み込みしても直した点数で表示される | 記録後に同じマスへ別の点数を書く。 | 位置は変わらず、直した点数が残る。 |
| 記録済みのマスをクリアすると、そのマスだけが空になり、再読み込みしても空のままになる | 2つのマスを記録して片方をクリアする。 | 片方だけ空で、もう片方は残る。 |
| 点数を書いた直後に一つ戻ると、そのマスが空に戻り、再読み込みしても空のままで、一つ進むと同じ点数が戻る | 記録→戻る→進む。 | 空に戻り、進めると元の点数になり、再読み込みでも保たれる。 |
| 入力中のラウンドを開くと、最初の空のマスが指されテンキーが展開され、完了のラウンドでは指されない | 途中まで記録済みのラウンドと完了のラウンド(detail)。 | 順に、最初の空のマスが指される・指されない。 |
| 他の端末で記録した入力中のラウンドを、取得後にオフラインで開くと、記録と合計と最初の空のマスとテンキーが表示される(detail。既存の「仮の矢」を置き換える) | 既存の経路を維持する。 | 最初の空のマスが指される。 |
| 全てのマスが埋まったラウンドは、完了を押すと確認なしで完了し、完了のラウンドで空のマスへ書くと入力中へ戻る(completion) | 既存の経路を維持する。 | マス目の用語での同じ結果。 |

E2Eの補助`createRound`は、記録済みの矢をマス(距離の添字、エンド、番号)で渡す形にし、矢のIDを引数に持たない。
`expectBalls`などの補助は、表示の順でなくマスの番号で玉を探す。

## 手動表示確認

ビルド済みの`pnpm preview`で次を確かめる。

- 空のマスが灰色の細い輪で、番号の文字がなく、記録済みの玉と区別でき、指す輪が主色になる。
- 点数を書いても玉が並び替わらず、動きが付かない。
- 読み上げが、空のマスは「{n}射目、空」で、記録済みの玉は名前が無く中の点数が読まれる。
- 射数/エンドが多い距離の段の折り返し、行の高さの揃い、320pxと横向きの収まり。
