# rounds/score-entry

## 目的

利用者が、射った矢の点数を1本ずつ素早く記録し、書き間違いをその場で直せるようにする。

## 要求

### 点数を書く

- 新しい矢を指して点数を書くと、その点数の矢が記録され、同じエンドに仮の矢が表示される。
- エンドの玉は入力の順によらず点数の高い順に並び、小計も入力の順によらず、再読み込みしても同じ並びと値で表示される。
- エンドが矢数に達すると、同じ距離の次のエンドに仮の矢が移る。
- 距離の最後のエンドが矢数に達すると、矢が指されなくなってテンキーが格納され、次の距離のエンドに仮の矢は表示されない。

### 書く矢を指す

- 記録済みの玉を押すと、その矢が指されて輪が付き、テンキーが展開される。
- エンドの空白を押すと、そのエンドに仮の矢が表示され、次の点数がそのエンドに記録される。
- 別の距離のエンドの空白を押すと、テンキーがその距離の的の点数のキーに切り替わる。
- エンドの番号、小計、満杯のエンドの玉以外の部分を押しても、指している矢とテンキーの表示は変わらない。

### 点数を直す・消す

- 記録済みの矢を指して別の点数を書くと、その矢の点数だけが変わって点数の高い順の位置へ並び直り、その矢が指されたままになる。直した点数は保持される。
- 記録済みの矢を指してクリアすると、その矢が消え、そのエンドに仮の矢が表示される。クリアは保持される。
- 新しい矢を指しているときは、クリアを押せない。

### 書き込みを戻す・やり直す

- 一つ戻ると、直前の書き込み(点数の記録、直し、クリア)が取り消され、戻した矢が指される(記録を戻すと矢が消え、そのエンドに仮の矢が表示される)。取り消しは保持される。
- エンドの最後の矢を記録して次のエンドへ移った直後に一つ戻ると、前のエンドの最後の矢が消え、前のエンドに仮の矢が表示される。
- 一つ進むと、取り消した書き込みがやり直され、やり直した矢が指される。やり直しは保持される。
- 取り消した後に点数を書くかクリアすると、取り消した書き込みはやり直せなくなる。
- 取り消せる書き込みが無いときは、一つ戻るを押せない。

### テンキーの表示と格納

- 矢数に達していないエンドがあるラウンドを開くと、展開したテンキーに、的にある点数のキーだけが表示される。
- テンキーを閉じると、矢が指されなくなり、テンキーが格納される。

### 指す矢の表示

- 矢を指した後、点数を入力した後に、指す矢が隠れずに見える。

## 対象外

- 射順、的の位置、射手の入力と表示は扱わない。
- 取り消しとやり直しは、この画面で自分が行った書き込みだけを対象にし、再読み込みや画面の移動で消える。
- 距離、エンド数、矢数、的の設定は、rounds/setupで扱う。
- 小計以外の集計と、ラウンドを開いたときに何も指さない場合は、rounds/detailで扱う。
- 書き込みの送信と再送、他の端末との同期は、rounds/syncで扱う。
- 入力の完了と完了の帯は、rounds/completionで扱う。
