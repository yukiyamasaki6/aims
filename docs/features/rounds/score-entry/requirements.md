# rounds/score-entry

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| score-01 | テンキーを格納したラウンド詳細画面でモバイル | マスをクリックする | そのマスが選択される<br>下パネルでテンキーが展開される<br>選択中のマスがテンキー上部までスライドする |
| score-02 | テンキーを格納したラウンド詳細画面でデスクトップ | マスをクリックする | そのマスが選択される<br>右パネルでテンキーが展開される |
| score-03 | ラウンド詳細画面で未入力のマスがある | /rounds/[id]を開く | 展開したテンキーに、的に対応する点数のキーのみが表示される<br>キーが的の配色に合わせて色分けされる |
| score-05 | テンキーを展開したラウンド詳細画面で的の異なる距離がある | 別の距離のマスをクリックする | そのマスの的に対応する点数のキーに切り替わる |
| score-07 | テンキーを展開したラウンド詳細画面 | 点数ボタンをクリックする | 選択中のマスへ点数が記録される<br>マス目の背景が的の配色を薄くしたトーンで色分けされる<br>次のマスが選択される<br>記録した点数が保持される |
| score-08 | テンキーを展開したラウンド詳細画面で選択中のマスに点数が記録されている | クリアボタンをクリックする | 選択中のマスの点数がクリアされる<br>前のマスが選択される<br>クリアが保持される |
| score-09 | テンキーを展開したラウンド詳細画面でモバイル | 下矢印をタップする | マスの選択が解除される<br>テンキーが格納される |
| score-10 | テンキーを展開したラウンド詳細画面でデスクトップ | 閉じるボタンをタップする | マスの選択が解除される<br>テンキーが格納される |
| score-11 | テンキーを展開したラウンド詳細画面で取り消せる記録がある | 一つ戻るボタンをクリックする | 直前の記録が取り消される<br>取り消したマスが選択される<br>取り消しが保持される |
| score-12 | テンキーを展開したラウンド詳細画面で取り消した記録がある | 一つ進むボタンをクリックする | 取り消した記録がやり直される<br>やり直したマスが選択される<br>やり直しが保持される |
| score-13 | テンキーを展開したラウンド詳細画面で取り消した記録がある | 点数ボタンをクリックする | 取り消した記録をやり直せなくなる |
| score-14 | テンキーを展開したラウンド詳細画面で取り消した記録がある、選択中のマスに点数が記録されている | クリアボタンをクリックする | 取り消した記録をやり直せなくなる |
