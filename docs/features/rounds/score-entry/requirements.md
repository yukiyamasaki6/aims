# rounds/score-entry

## 目的

利用者が、射った矢の点数を1本ずつ素早く記録し、書き間違いをその場で直せるようにする。

## 要求

### 点数を書く

- エンドには射数/エンドの個数のマスが番号順に並び、矢の無いマスも表示される。
- 空のマスを指して点数を書くと、そのマスに記録され、そのマスの番号がその矢の射順になる。他のマスは動かない。
- 空のマスへ点数を書いた後は、書いたマスより後ろの最初の空のマスが指される。他の利用者が埋めたマスは対象にならず、空のマスだけが対象になる。
- 同じエンドに後ろの空のマスが無いときは、同じ距離の後ろのエンドの最初の空のマスが指される。
- 同じ距離の後ろに空のマスが無いときは、マスが指されなくなってテンキーが格納され、次の距離のエンドのマスは指されない。前方に残った空のマスは、押して埋められる。
- 記録済みのマスの直しの後は、後ろの空のマスへ移らず、そのマスが指されたままになる。
- 点数の高い順の並べ替えは行わず、マスの位置は入力の順や点数によらず、再読み込みしても同じ位置と小計で表示される。
- 複数の利用者が同じエンドへ入力しても、同じマスへの記録は後に保存された点数で置き換わる。射手別のマスは持たない。

### 書くマスを指す

- マスを押すと、そのマスが指されて輪が付き、テンキーが展開される。空のマスも同じである。
- 別の距離のエンドのマスを押すと、テンキーがその距離の的の点数のキーに切り替わる。
- エンドの番号、小計、マス以外の部分を押しても、指しているマスとテンキーの表示は変わらない。

### 点数を直す・消す

- 記録済みのマスを指して別の点数を書くと、そのマスの点数だけが変わり、位置と射順は変わらず、そのマスが指されたままになる。直した点数は保持される。
- 記録済みのマスを指してクリアすると、そのマスだけが空に戻り、他のマスは動かない。そのマスが指される。クリアは保持される。
- 空のマスを指しているときは、クリアを押せない。

### 書き込みを戻す・やり直す

- 一つ戻ると、直前の書き込み(点数の記録、直し、クリア)が取り消される。取り消しは保持される。
- 直しかクリアを一つ戻すと、戻したマスが指される。
- 点数の記録を一つ戻すと、そのマスが空に戻り、指される。
- エンドの最後のマスを記録して次のエンドへ移った直後に一つ戻ると、前のエンドの最後に記録したマスが空に戻り、指される。
- 一つ戻る書き込みは、他の端末が後から同じマスへ記録していても、戻した内容(元の点数または空)で置き換わる。
- 一つ進むと、取り消した書き込みがやり直され、やり直したマスが指される。やり直しは保持される。
- 取り消した後に点数を書くかクリアすると、取り消した書き込みはやり直せなくなる。
- 取り消せる書き込みが無いときは、一つ戻るを押せない。

### テンキーの表示と格納

- 空のマスがあるラウンドを開くと、展開したテンキーに、的にある点数のキーだけが表示される。
- テンキーを閉じると、マスが指されなくなり、テンキーが格納される。
- テンキーが格納されている間、点数のキーは表示されず、操作もTabの移動の対象にならない。

### 指すマスの表示

- マスを指した後、点数を入力した後に、指すマスが隠れずに見える。
- 他の端末の変化で指すマスが直されたときは、スクロールで追わない。
- 向き、窓の幅、テンキーの高さ、行の段数が変わったときも、指すマスが隠れずに見える。

## 対象外

- 的の位置、射手の入力と表示は扱わない。射順は、マスの番号として記録され、別に入力する操作は持たない。
- 取り消しとやり直しは、この画面で自分が行った書き込みだけを対象にし、再読み込みや画面の移動で消える。
- 距離、エンド数、射数/エンド、的の設定は、rounds/setupで扱う。
- 小計以外の集計と、ラウンドを開いたときに何も指さない場合は、rounds/detailで扱う。
- 書き込みの送信と再送、他の端末との同期は、rounds/syncで扱う。
- 入力の完了と完了の帯は、rounds/completionで扱う。
