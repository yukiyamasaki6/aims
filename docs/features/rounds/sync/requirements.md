# sync

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| sync-01 | 未送信の操作がないラウンド詳細画面 | 画面を開く | 「同期済み」と表示される |
| sync-02 | オンラインのラウンド詳細画面で送信が完了していない | ラウンド設定を保存する | 「同期中…」と表示される |
| sync-03 | オンラインのラウンド詳細画面で送信が成功する | ラウンド設定を保存する | 「同期済み」と表示される |
| sync-04 | オフラインのラウンド詳細画面 | ラウンド設定を保存する | 「同期保留中」と表示される |
| sync-05 | 「同期保留中」のラウンド詳細画面 | オンラインへ復帰する | 自動で再送され、「同期済み」と表示される |
| sync-06 | オンラインのラウンド詳細画面で送信が失敗しリトライ回数が残っている | ラウンド設定を保存する | 「同期中…」と表示され、「同期保留中」と表示されない |
| sync-07 | リトライ待機中のラウンド詳細画面 | バックオフの待機時間が経過する | 同じ操作が再送される |
| sync-12 | オフラインのラウンド詳細画面で、同じマスへ点数を記録し、クリアし、別の点数を記録した | オンラインへ復帰する | 最後の点数が保存され、再読み込みしても最後の点数が表示される |
| sync-11 | 点数を記録したが送信に失敗して未送信のラウンド詳細画面 | 通信が回復した状態で再読み込みする | 未送信の点数が失われず再送され、「同期済み」と表示される<br>記録した点数が保持される |
| sync-13 | オンラインのラウンド詳細画面で、点数の送信が一時的に失敗してリトライ待機中であり、同じマスの点数を記録し直した | 通信が回復した状態で再読み込みする | 記録し直した点数が保持され、先の点数に戻らない |
| sync-09 | オンラインのラウンド詳細画面で、送信の失敗が5回以上続いている | 送信が成功するようになる | 自動で再送され、「同期済み」と表示される<br>それまで「同期失敗」と表示されない |
| sync-14 | サーバーが契約の不一致として拒否する点数があるラウンド詳細画面 | 同じマスへ点数を記録し直し、別のマスにも点数を記録して、再読み込みする | 記録し直した点数と別のマスの点数が保存される<br>「同期済み」と表示される |
| sync-15 | 他端末の矢がある距離で、オフラインで的を変え、両方の的にある点数を記録した | オンラインへ復帰する | 全ての点数が表示され、「同期済み」と表示される |
| sync-16 | 他端末の的にしか無い点数が先に確定した距離で、オフラインで的を変えた | オンラインへ復帰する | 的は元のままで、先の点数と有効な点数だけが表示される |
| sync-17 | 5エンド目の点数が確定済みの距離で、オフラインでエンド数を4へ変えた | オンラインへ復帰する | エンド数は5のままで、5エンド目の点数が残る |
| sync-18 | 2端末が同じ距離を別の的・エンド数・矢数へ変えた | 両方がオンラインへ復帰する | 後に確定した的・エンド数・矢数になり、2つが混ざらない |
| sync-19 | 他端末が種別をフィールド以外へ変えた後で、オフラインでUnmarkedの距離を追加し点数を記録した | オンラインへ復帰する | その距離と点数は表示されず、他の距離は変わらない |
| sync-20 | 他端末がラウンドを削除した | 削除の前と後に届いた矢と構成の変更が送られる | どれも表示されず、「同期済み」と表示される |
| sync-21 | 2端末が同じマスへ、互いに知らずに別の点数を記録した | 両方がオンラインへ復帰する | 後に確定した点数が表示され、異なるマスの点数は両方残る |
| sync-22 | 認可で拒否される操作がある | 操作が送られる | その操作だけが消え、「同期済み」と表示される |
| sync-23 | 先に確定した点数があるマスへ、古い的の前提で無効な点数が後に確定する | オンラインへ復帰する | 先の点数が残る |
| sync-24 | 2端末がラウンドの別の項目と、同じ項目を変えた | 両方がオンラインへ復帰する | 同じ項目は後の値になり、別の項目は両方の値が残る |
| sync-25 | 削除された距離への点数の送信の応答が失われ、遅れて再送される | 再送が届く | 点数は表示されない |
| sync-26 | 空のマスへの取り消しの応答が失われ、他端末がそのマスへ点数を記録した | 取り消しが再送される | 他端末の点数が残る |
| sync-27 | Unmarkedの距離の追加が先に確定した後に、他端末の種別の変更が届く | オンラインへ復帰する | 種別はフィールドのままで、距離と点数が残る |
| sync-28 | 他端末の矢がある距離で、オフラインで的と距離(m)を同じ保存で変えた | オンラインへ復帰する | 的はそのままで、距離(m)は変わる |
| sync-29 | 他端末がUnmarkedの距離を追加した後に、オフラインで種別と名前を同じ保存で変えた | オンラインへ復帰する | 種別はそのままで、名前は変わる |
| sync-30 | 他端末が距離(m)を空にした後に、オフラインでMarkedへ変えた | オンラインへ復帰する | Unmarkedのままで、距離(m)は空のままである |
| sync-31 | サインインが必要で送れないラウンド詳細画面 | ラウンド設定を保存する | 「同期保留中」と表示される |
| sync-32 | Unmarkedで距離(m)が空の距離のラウンド詳細画面 | Markedにして距離(m)を入力し、1回で保存する | Markedと距離(m)が両方反映され、再読み込みしても残る |
