# rounds/sync

## 目的

利用者が、通信の状態や使う端末・タブによらず、記録した点数と変えた設定を失わずに保存し、どの端末でも同じ内容を見られるようにする。

## 要求

### 記録や設定を変える

- ラウンドの詳細で点数を記録したり設定を保存したりすると、操作しなくても保存される。
- 点数を記録している間も、送信を待つ間、オフラインの間、送信に失敗して送り直す間、送れない記録を消した後も、同期の状態や失敗は画面に表示されない。
- オフラインで点数を記録したり、設定を保存したり、入力を完了にしたりすると、オンラインに戻ったときに操作しなくても保存され、他の端末でも同じ内容で表示される。
- オフラインで点数を記録し、その矢を消して別の点数を記録すると、オンラインに戻った後は最後の点数だけが保存され、再読み込みしても最後の点数だけが表示される。

### ほかの画面へ移る、アプリを閉じる

- 点数を記録した後にオフラインのままラウンド一覧へ移っても、オンラインに戻ると、そのラウンドを開き直さずに保存される。
- 未送信の点数を残してアプリを閉じても、通信のある状態でラウンド一覧を開くと、そのラウンドを開かずに保存される。
- 点数の送信中にラウンド一覧へ移っても、点数は1回だけ保存される。

### ラウンドを始めたとき

- オフラインで開始したラウンドは、ラウンド一覧へ移っていても、オンラインに戻ると開き直さずに保存され、ラウンド一覧に1件だけ表示される。
- ラウンドの作成の送信が失敗している間に追加した距離と記録した点数は、再読み込みしても表示される。
- ラウンドの作成の送信が失敗している間に追加した距離と記録した点数は、送信が回復すると保存される。
- 開始したラウンドの作成が、受け付けられない形として拒否されると、ラウンドの詳細に「ラウンドが見つかりません。」と表示され、ラウンド一覧にも表示されない。

### 送信に失敗したとき

- 送信に失敗しても、待ってから自動で送り直し、失敗が5回以上続いても、通信が回復すると操作しなくても保存される。
- 送信に失敗して未送信の点数と、送り直しを待つ間に直した点数は、再読み込みしても失われず、直した後の点数で保存される。
- 受け付けられない形の記録や、権限が無い操作が拒否されると、その操作だけが消え、同じラウンドや他のラウンドの他の記録は保存される。
- 一方のラウンドの送信が失敗し続けても、他のラウンドの記録は保存される。

### サインインが切れたとき、利用者が替わったとき

- サインインが切れて送れなかった記録は、ラウンド一覧にいるままサインインし直すと、そのラウンドを開き直さずに保存される。
- サインインの有効期限の更新が、サーバーの側の更新と重なっても、記録した点数は保存される。
- 別の利用者の未送信の記録が残る端末でサインインしても、その記録は送られず、表示されない。
- 別の利用者の未送信の記録は、その利用者が再びサインインすると保存される。

### 他の端末とラウンドや距離の設定を同時に変えたとき

- 複数の端末で同じ項目を変えると、後に保存された値になる。
- 複数の端末で別々の項目を変えると、ラウンドの状態の変更を含めて両方の変更が残る。
- 距離の的・エンド数・矢数は1組として、複数の端末で変えると後に保存された組になり、組が混ざらない。
- 他の端末が記録した矢がある距離の的・エンド数・矢数を変えると、その矢が変更後に収まるなら、変更が効いて全ての点数が残る。
- 他の端末が記録した矢がある距離の的・エンド数・矢数を変えると、その矢が変更後に収まらないなら、的・エンド数・矢数は元のままで矢が残る。
- 的・エンド数・矢数が効かなくても、同じ保存で変えた距離(m)は保存される。
- Unmarkedの距離があるラウンドの種別を、フィールド以外へ変えても効かず、同じ保存で変えた名前は保存される。
- 他の端末が種別をフィールド以外へ変えた後に追加したUnmarkedの距離と、その距離の点数は、保存されず表示されず、他の距離は変わらない。
- 他の端末が距離(m)を空にした後に、その距離をMarkedへ変えても効かず、Unmarkedのまま距離(m)も空のままになる。
- Unmarkedで距離(m)が空の距離を、Markedにして距離(m)を入れて1回で保存すると、両方が保存され、再読み込みしても残る。
- オフラインで距離を追加して削除し、もう一度追加すると、オンラインに戻った後、追加した距離が表示され、再読み込みしても表示される。
- 複数の端末が同じ位置に同時に距離を追加すると、両方の端末で2つの距離が同じ順で表示され、エラーは表示されず、オフラインで記録した点数も残る。

### 他の端末と同じエンドへ記録したとき

- 複数の端末が同じエンドへ互いに知らずに記録した矢は、それぞれ別の矢として残り、どの端末でも表示される。
- 複数の端末が同じエンドへ記録して矢数を超えると、先に保存された矢数分の矢が残り、両方の端末で、表示と再読み込みの後に矢数を超えず、知らせる表示は出ない。
- 一つ戻るで取り消されるのは、この端末が記録した矢だけで、他の端末が同じエンドへ記録した矢は残る。
- 他の端末が消した矢を、この端末で知らずに直すと、その矢は直した点数で再び表示される。
- この端末で直した矢を、後で他の端末が消すと、その矢は表示されない。
- 消した矢を一つ戻るで戻すとき、そのエンドが他の端末の記録で矢数に達していれば、矢数を超えず、消した矢は戻らない。
- オフラインで直した点数が、他の端末が先に変えた的に無い点数のときは効かず、他の端末の点数が残る。
- 射手をこの端末の利用者として記録した矢を書き換えても、点数だけが変わり、射手は残る。
- 他の端末の内容と重なって効かなかった記録や変更は、オンラインのままなら、再読み込みしなくても、保存された内容の表示に戻る。

### 他の端末がラウンドや距離を削除したとき

- 他の端末がラウンドを削除すると、その前後に送られた記録や変更は表示されず、ラウンドは見つからない表示になる。
- 他の端末が削除した距離への記録は、送信の応答が失われて送り直されても表示されない。

### 複数のタブで使うとき

- 複数のタブで同じ矢を変えたり消したりすると、後に行った操作の結果が保存される。
- 複数のタブに未送信の記録があるとき、一方のタブを閉じても、残ったタブで両方の記録が保存される。

### オフラインのまま開き直したとき

- オフラインで記録した入力中のラウンドは、アプリを開き直してオフラインのまま開いても表示される。
- オフラインで記録した入力中のラウンドをオフラインのまま開いている間に他の端末が記録した点数は、オンラインに戻ると操作しなくても表示され、両方の点数が保存される。

## 対象外

- ラウンドの開始の操作はrounds/start、削除の操作と確認はrounds/delete、入力の完了の操作はrounds/completion、一覧の表示と取得はrounds/historyで扱う。
- 同期の状態、送信の失敗、拒否されて消した操作を、利用者に知らせることは扱わない。
- 矢数を超えて効かなかった記録と、射順が重なって効かなかった射順を、利用者に知らせることは扱わない。
- アプリの画面を全て閉じている間の送信は扱わない。
- 他の端末の操作で置き換わった値を見て選ぶことや、元に戻すことは扱わない。
- 他の端末の変更を、開いている画面へすぐ反映することは扱わない。
- 共有の端末で、別の利用者の未送信の記録を秘匿することは扱わない。
