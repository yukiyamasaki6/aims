# rounds/shooters

## 目的

1人で記録しても、ラウンドのどの矢を誰が射ったかが分かるように、矢を射手ごとに記録する。
アカウントのない人の矢も、射手として記録できる。
利用者がアカウントを削除しても、その人の矢は、他の射手と区別できるまま、その人に結び付かない形で残る。

## 要求

### 矢を射手ごとに記録する

- 各ラウンドは射手の一覧を持ち、どの矢も、そのラウンドの射手を1人だけ持つ。射手のない矢は保存されない。
- 射手には、利用者に紐づく射手と、利用者に紐づかない射手の2つがある。
- 紐づかない射手は、アカウントのない人を表すために加えた射手も、アカウントの削除で紐づけが外れた射手も、区別せず同じに扱われる。
- 利用者に紐づけられるのは、そのラウンドの射つ人(rounds/roles)だけである。
- 1つのラウンドで、1人の利用者に紐づく射手は1つだけである。別の端末から同時に同じ利用者の矢を記録しても、その利用者の射手は1つだけである。
- 矢の記録では、誰の記録でも射手の指定が要り、射手を指定しない記録は保存されない。
- 射手として指定できるのは、そのラウンドの射つ人と、そのラウンドの紐づかない射手である。射つ人でない利用者(代理の人自身を含む)と、他のラウンドの射手は指定できない。
- 矢は、記録で指定した射手の矢になる。
- 射つ人と代理の人は、矢の射手を、そのラウンドの別の射手に付け替えられる。付け替えた後に、元の射手を指定して戻せる。

### 画面から記録する

- 画面の見た目は変わらず、画面が射手を指定して記録する。
- 一度も記録していないマスに画面で記録すると、記録した射つ人の矢になる。
- 記録済みのマスを直す、消してから記録する、一つ戻る・一つ進むで書き直すと、そのマスの射手は変わらない(紐づかない射手のマスを含む)。

### アカウントのない人の射手を加える

- 射つ人と代理の人は、そのラウンドに、利用者に紐づかない射手を、番号を選んで名前なしで加えられる。
- 既にある番号を選ぶと、新しい射手は増えず、その番号の射手を指す。
- 加えた射手は、矢の射手として指定できる。
- 射つ人でも代理の人でもない利用者は、射手を加えられない。

### 射手の番号

- 全ての射手が番号(射手1、射手2…)を持ち、番号は記録する人が選ぶ。システムが加わった順に番号を付けることはしない。
- アカウントのない人は、記録する人が選んだ番号の射手になる。
- ラウンドを作った人は、射手1に結び付いて始まる。
- 番号に結び付く利用者は、後から別の利用者に変わりうる。番号は変わらない。利用者が変わると、変わる前の矢も含めて、その番号の矢は全て変わった後の利用者の矢として扱われる。
- 同じラウンドの同じ番号は、同じ人を表す。別々の端末で(通信できない間を含む)同じ番号を選んだ記録は、同じ射手の矢になる。
- 一度付いた番号は、その後の記録・付け替え・匿名化で変わらない。
- 紐づけが外れた射手は、その番号で表される。
- 射手は、ラウンドの射手の一覧から削除されない。矢の取り消し・付け替え・距離の削除の後も、射手は一覧に残る。

### アカウントを削除したとき

- 削除した人に紐づく射手がある、残る全てのラウンド(参加の有無と矢の有無を問わない)で、その射手は紐づけが外れて、利用者に紐づかない射手になる。その射手の矢と矢の変更履歴は、その射手のもののまま残る。
- 紐づけが外れても、射手の数と番号は変わらない。矢を記録していない参加者が削除しても、射手は増えない。
- 紐づけが外れた射手は、同じラウンドの他の射手と区別できる。同じラウンドで2人が削除しても(同時でも)、2人の矢と履歴は別々の射手のものとして残る。
- 紐づけが外れた射手は、削除した人の利用者を指さない。削除の後、削除した人の利用者IDは、どのラウンドの射手にも残らない。
- 矢の変更履歴の射手は、記録ごとにその記録の時点の射手(番号)を指し、取り消した矢と付け替える前の射手を含めて、別の射手の記録が同じ射手にまとまらない。
- バックアップから復元した後も、各射手の番号は削除の時と同じである。取得の後に同じラウンドの2人が削除した場合や、削除の記録を書いた後に削除が取り消された利用者がいる場合も、復元で番号は変わらない。

## 対象外

- 射手を選ぶ・表示する画面。
- 射手の名前(紐づかない射手に名前を付けるか、付け方・変え方・消し方、紐づく射手の表示)。
- 番号を選ぶ画面。
- ラウンドを作った人以外の射つ人を番号に結び付ける操作と、別の利用者を同じ番号に結び付けた場合などの扱い。
- 番号に結び付く利用者を変える操作。
- 射つ人・代理の人を加える操作と、ラウンドから外れる操作(rounds/roles)。
- 複数人で1つのラウンドを射つ共同型の画面。
- チーム。
