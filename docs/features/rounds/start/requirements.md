# rounds/start

## 目的

利用者が、プリセットの構成を選んで、または選ばずに、ラウンドの記録をすぐに始められるようにする。

## 要求

### ラウンドを始める

- 認証済みで開くと、個人プリセットと公式プリセットの一覧が表示される。
- プリセットを選ぶと、開始ボタンに選んだプリセットの名前が表示され、その距離構成が展開して表示される。
- プリセットを選んで開始すると、そのプリセットの距離構成のラウンドが作られ、ラウンドの画面へ移動する。
- プリセットを選ばずに開始すると、距離のないラウンドが作られて保存され、ラウンドの画面へ移動する。
- 開始のときにセッションの更新が別の書き手の更新と重なっても、開始してラウンドの画面でラウンドが表示される。

### ほかの画面へ進む

- 「一覧へ戻る」リンクで、ラウンド一覧へ移動できる。

### オフラインや、認証を確認できないとき

- 的の一覧を端末に保存済みなら、オフラインでも、認証を確認できない(通信できない)ときも、開始してラウンドの画面でラウンドが表示される。

### 端末に保存したプリセットを使うとき

- 一度オンラインで表示した後は、オフラインでも、個人プリセットと公式プリセットの一覧が表示され、「ネットワークに接続されていません」は表示されない。
- 一度オンラインで表示した後は、オフラインでも、選んだプリセットの距離構成で開始できる。
- 端末に保存したプリセットがサーバーで削除された後にオンラインで開くと、削除されたプリセットは表示されない。
- 別のユーザーでサインインし直した後は、オフラインでも、前のユーザーの個人プリセットは表示されない。

### サインインが必要なとき、または一覧を取得できないとき

- 未認証が確認されたときは、開始するとエラーが表示され、ラウンドの画面へ移動しない。
- プリセットを端末に保存しておらず、通信できないときは、「読み込めませんでした。」と再試行が表示される。
- プリセットを端末に保存しておらず、取得がエラーになるときは、エラーメッセージが表示される。
- プリセットを端末に保存しておらず、取得できない(通信できない)か取得がエラーになるときも、「一覧へ戻る」リンクと開始ボタンは使え、プリセット無しで開始できる。

## 対象外

- プリセットの保存と削除は、rounds/presetで扱う。
- 開始後のラウンドの名前、実施日、種別、弓種、距離構成の入力は、rounds/setupで扱う。
- プリセットを端末に保存していないときのオフラインの表示は、app/offline-pwaで扱う。
- 的の一覧を端末に保存していないときに、通信できないまま開始したラウンドの表示は、rounds/detailで扱う。
- 未認証で開いたときのサインイン画面への移動は、app/navigationで扱う。
