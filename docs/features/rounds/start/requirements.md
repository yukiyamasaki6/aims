# rounds/start

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| start-01 | ラウンド作成画面で認証済み | /rounds/newを開く | 個人プリセットと公式プリセットの一覧が表示される |
| start-04 | ラウンド作成画面 | 「一覧へ戻る」リンクをクリックする | /roundsへ遷移する |
| start-05 | ラウンド作成画面でプリセットが未選択 | プリセットをクリックする | クリックしたプリセットが選択される<br>開始ボタンに選択中のプリセット名が表示される<br>選択中のプリセットの距離構成が展開表示される |
| start-08 | ラウンド作成画面でプリセットが未選択 | 開始ボタンをクリックする | 空の距離構成のラウンドが作成される<br>「同期済み」と表示される |
| start-09 | ラウンド作成画面でプリセットが選択されている | 開始ボタンをクリックする | プリセットの距離構成のラウンドが作成される |
| start-11 | ラウンド作成画面 | 開始ボタンをクリックする | /rounds/[id]へ遷移する |
| start-17 | オフラインのラウンド作成画面 | 開始ボタンをクリックする | /rounds/[id]へ遷移し、ラウンドが表示される<br>「同期保留中」と表示される |
| start-18 | ラウンド作成画面で認証を確認できない（通信できない） | 開始ボタンをクリックする | /rounds/[id]へ遷移し、ラウンドが表示される<br>「同期中…」と表示される |
| start-13 | ラウンド作成画面で未認証が確認されている | 開始ボタンをクリックする | エラーメッセージが表示される |
| start-15 | ラウンド作成画面でプリセットを取得できない（通信できない） | /rounds/newを開く | 「一覧へ戻る」リンクと開始ボタンが表示される<br>「読み込めませんでした。」と再試行ボタンが表示される<br>プリセット無しで開始できる |
| start-16 | ラウンド作成画面でプリセットの取得がエラーになる | /rounds/newを開く | エラーメッセージが表示される<br>プリセット無しで開始できる |
