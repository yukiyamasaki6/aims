# auth/signin

## 目的

登録済みの利用者が安全に認証し、目的の画面へ進めるようにする。

## 要求

### サインインする

- 確認済みアカウントの正しいメールアドレスとパスワードを入力し、セキュリティチェックを完了した利用者は、サインインしてラウンド一覧へ進める。
- 許可された遷移元からサインインした利用者は、認証後にその画面へ戻れる。
- 外部URLなど許可されていない遷移元を指定した利用者は、認証後に外部へ送られずラウンド一覧へ進む。
- セキュリティチェックに操作が必要な場合は、チェック欄が表示される。
- チェック欄でセキュリティチェックを完了すると、認証情報を送信できる。

### ほかの画面へ進む

- パスワードを忘れた利用者は、パスワード再設定へ進める。
- アカウントを持たない利用者は、サインアップへ進める。

### 認証済みで開く

- 認証済みの利用者がサインイン画面を開くと、ラウンド一覧へ移動する。
- 認証済みの利用者が許可された遷移元付きでサインイン画面を開くと、その画面へ移動する。

### 入力の不備、重複した送信、失敗があるとき

- メールアドレスが未入力または形式不正、パスワードが未入力、セキュリティチェックが未完了の場合は、理由が表示され、認証は行われない。
- 認証処理中に再度送信しても、認証処理は重複して行われない。
- 認証または通信に失敗した場合は、理由が表示され、セキュリティチェックをやり直して再送信できる。

## 対象外

- アカウントの作成とパスワードの再設定は、それぞれの機能で扱う。
- サインインの再試行回数は制限しない。
