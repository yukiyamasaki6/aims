# auth/signin

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| signin-01 | サインイン画面で確認済みアカウントのメールアドレスとパスワードを入力している<br>captchaが完了している<br>認証が成功する | サインインボタンをクリックする | /roundsへ遷移する |
| signin-11 | サインイン画面を遷移元(/rounds/new)付きで開いている<br>確認済みアカウントの認証情報を入力している<br>captchaが完了している<br>認証が成功する | サインインボタンをクリックする | 遷移元の/rounds/newへ遷移する |
| signin-12 | サインイン画面を外部URLの遷移元付きで開いている<br>確認済みアカウントの認証情報を入力している<br>captchaが完了している<br>認証が成功する | サインインボタンをクリックする | /roundsへ遷移する<br>外部へ遷移しない |
| signin-02 | サインイン画面 | 「パスワードをお忘れですか」リンクをクリックする | /reset-passwordへ遷移する |
| signin-03 | サインイン画面 | 「サインアップ」リンクをクリックする | /signupへ遷移する |
| signin-04 | 任意の画面で認証済み | /signinを開く | /roundsへリダイレクトされる |
| signin-13 | 任意の画面で認証済み | 遷移元(/rounds/new)付きの/signinを開く | 遷移元の/rounds/newへリダイレクトされる |
| signin-05 | サインイン画面でメールアドレスが未入力 | サインインボタンをクリックする | エラーメッセージが表示される |
| signin-08 | サインイン画面でエラーが表示されている | サインインボタンをクリックする | 表示中のエラーが消える<br>新しいエラーが表示される |
| signin-09 | サインイン画面で認証の完了が遅い | サインインボタンをクリックする | サインインボタンが無効になる |
| signin-10 | サインイン画面で認証が失敗する | サインインボタンをクリックする | エラーメッセージが表示される<br>サインインボタンが再度有効になる<br>captchaが未完了に戻る |
| signin-14 | サインイン画面でセキュリティチェックの操作が求められる | /signinを開く | チェックの枠が表示される<br>チェックを完了するとサインインボタンで送信できる |
