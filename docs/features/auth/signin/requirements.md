# auth/signin

## 目的

登録済みの利用者が安全に認証し、目的の画面へ進めるようにする。

## 要求

### サインインする

- 確認済みアカウントの正しいメールアドレスとパスワードを入力し、セキュリティチェックを完了した利用者は、サインインしてホームへ進める。
- 許可された遷移元からサインインした利用者は、認証後にその画面へ戻れる。
- 外部URLなど許可されていない遷移元を指定した利用者は、認証後に外部へ送られずホームへ進む。
- セキュリティチェックに操作が必要な場合は、チェック欄が表示される。
- チェック欄でセキュリティチェックを完了すると、認証情報を送信できる。
- セキュリティチェックが完了する前に送信しても、エラーにならず送信中の表示になり、完了すると自動で認証が進む。失敗の直後や、チェックの有効期限が切れた後でも同じである。
- パスワードを入力欄で表示・非表示に切り替えて確かめられる(切り替えても入力値は保たれる)。
- メールアドレスとパスワードの入力欄は、ブラウザやパスワード管理ツールが、保存済みの認証情報の自動入力と保存を提案できる欄として認識される。

### ほかの画面へ進む

- パスワードを忘れた利用者は、パスワード再設定へ進める。
- アカウントを持たない利用者は、ヘッダーのサインアップからサインアップへ進める。本文にサインアップへのリンクは置かない。

### 認証済みで開く

- 認証済みの利用者がサインイン画面を開くと、ホームへ移動する。許可された遷移元が付いていれば、その画面へ移動する。

### 入力の不備、重複した送信、失敗があるとき

- メールアドレスが未入力または形式不正、パスワードが未入力の場合は、セキュリティチェックの状態に関わらず、該当する理由が全て表示され、認証は行われない。
- セキュリティチェックに追加の操作が必要な間は、送信中のまま待ち、利用者が完了すると自動で認証が進む。追加の操作が必要になった、またはチェックが失敗したことで表示されたチェック欄は、完了した後も、チェックが取り直されるまで表示されたままで(まだ操作を押していなくても同じ)、取り直されると畳まれる(取り直しで再び追加の操作が必要になれば、再び表示される)。操作が結果を返しても、チェックが取り直されなければ畳まれない。成功で画面が遷移するときは画面ごと消える。
- セキュリティチェックが失敗した、または追加の操作が無いまま一定時間完了しない場合は、失敗が表示されて送信中が解け、完了するまで認証は行われない。失敗の後に再度操作した場合も、すぐには失敗を表示せず、改めて待つ。
- 認証処理中に再度送信しても、認証処理は重複して行われない。
- 認証に失敗した場合(通信の失敗を含む)は、理由が表示され、セキュリティチェックをやり直して再送信できる。
- 端末がオフラインの状態で送信した場合は、セキュリティチェックの状態によらず「ネットワークに接続されていません。接続を確認してから再度お試しください。」が表示され、認証処理は行われない(入力に不備がある場合は、その理由が表示される)。

## 対象外

- アカウントの作成とパスワードの再設定は、それぞれの機能で扱う。
- サインインの再試行回数は制限しない。
