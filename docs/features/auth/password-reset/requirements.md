# auth/password-reset 廃止

## 目的

パスワード再設定を提供せず、メールOTPだけで認証する。

## 要求

### 再設定URLへアクセスする

- `/reset-password`のページ・ルートは存在せず、他の存在しないURLと同じ扱いになる。
- 互換ページ・遷移専用入口・専用のリダイレクトを提供しない。
- 再設定の入力・送信・確認を実行できず、画面・メールから再設定へ誘導しない。

### パスワード操作を直接要求する

- 直接APIで設定・変更・再設定を試みた後も、パスワードによる新規ログインは成立しない。

## 対象外

- 旧URLの互換対応と、以前のパスワードでの復帰。
