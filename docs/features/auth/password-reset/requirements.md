# auth/password-reset

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| password-reset-01 | メール入力画面 | サインインに戻るリンクをクリックする | /signinへ遷移する |
| password-reset-02 | メール入力画面で送信が成功する | 送信ボタンをクリックする | コード入力画面へ進む<br>メールが届かない場合の確認事項が案内される<br>再送のクールダウンが始まる |
| password-reset-03 | コード入力画面 | 戻るボタンをクリックする | 入力済みのメールアドレスが保持されたまま、メール入力画面へ戻る |
| password-reset-04 | コード入力画面で再送が成功する | 再送ボタンをクリックする | 認証コードが再送される<br>captchaが未完了に戻る<br>再送・確認・戻るボタンが再度有効になる |
| password-reset-05 | コード入力画面で確認が成功する | 確認ボタンをクリックする | パスワード設定画面へ進む |
| password-reset-06 | パスワード設定画面で変更が成功する | 変更ボタンをクリックする | パスワードが変更される<br>サインアウトされる<br>/signinへ遷移する |
| password-reset-07 | コード入力画面でクールダウン中 | 再送ボタンをクリックする | クールダウン中のエラーが表示される |
| password-reset-08 | メール入力画面で送信の完了が遅い | 送信ボタンをクリックする | 送信ボタンが無効になる |
| password-reset-10 | コード入力画面で確認の完了が遅い | 確認ボタンをクリックする | 確認・再送・戻るボタンが無効になる |
| password-reset-11 | パスワード設定画面で変更の完了が遅い | 変更ボタンをクリックする | 変更ボタンが無効になる |
| password-reset-13 | メール入力画面でメールアドレスの形式が不正 | 送信ボタンをクリックする | エラーメッセージが表示される |
| password-reset-15 | メール入力画面で送信が失敗する | 送信ボタンをクリックする | エラーメッセージが表示される<br>送信ボタンが再度有効になる<br>captchaが未完了に戻る |
