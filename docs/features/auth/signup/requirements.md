# auth/signup

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| signup-01 | メール入力画面で未確認のメールアドレスを入力している<br>captchaが完了している<br>認証コードの送信が成功する | 送信ボタンをクリックする | コード入力画面へ進む<br>再送のクールダウンが始まる<br>メールが届かない場合の確認事項が案内される |
| signup-02 | コード入力画面 | 戻るボタンをクリックする | 入力済みのメールアドレスが保持されたまま、メール入力画面へ戻る |
| signup-03 | コード入力画面でクールダウンが終了している<br>captchaが完了している | 再送ボタンをクリックする | 認証コードが再送される<br>captchaが未完了に戻る<br>再送・確認・戻るボタンが再度有効になる |
| signup-04 | コード入力画面で正しい認証コードを入力している<br>確認が成功する | 確認ボタンをクリックする | パスワード設定画面へ進む |
| signup-05 | パスワード設定画面で要件を満たすパスワードを入力している<br>登録が成功する | 登録ボタンをクリックする | /roundsへ遷移する |
| signup-06 | メール入力画面 | サインインリンクをクリックする | /signinへ遷移する |
| signup-08 | メール入力画面でメールアドレスが未入力 | 送信ボタンをクリックする | エラーメッセージが表示される |
| signup-10 | メール入力画面で送信の完了が遅い | 送信ボタンをクリックする | 送信ボタンが無効になる |
| signup-11 | コード入力画面でクールダウン中 | 再送ボタンをクリックする | クールダウン中のエラーが表示される |
| signup-15 | コード入力画面で確認の完了が遅い | 確認ボタンをクリックする | 確認・再送・戻るボタンが無効になる |
| signup-17 | パスワード設定画面で登録の完了が遅い | 登録ボタンをクリックする | 登録ボタンが無効になる |
| signup-18 | メール入力画面で確認済みのメールアドレスを入力している<br>captchaが完了している | 送信ボタンをクリックする | エラーメッセージが表示される<br>送信ボタンが再度有効になる |
| signup-19 | メール入力画面で送信が失敗する | 送信ボタンをクリックする | エラーメッセージが表示される<br>送信ボタンが再度有効になる<br>captchaが未完了に戻る |
