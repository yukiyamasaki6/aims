# auth/signup

## 目的

アカウントを持たない利用者がメールアドレスを確認し、パスワードを設定してAIMSを使い始められるようにする。

## 要求

### 登録する

- 未登録のメールアドレスへ届いた認証コードを確認し、要件を満たすパスワードを設定した利用者は、登録してラウンド一覧へ進める。

### 認証コードの入力中

- 認証コードを送信した利用者は、再送できるまでの時間とメールが届かない場合の確認事項が分かる。
- 認証コード入力からメール入力へ戻った利用者は、入力済みのメールアドレスを再利用できる。
- 再送待機時間が終わりセキュリティチェックを完了した利用者は、新しい認証コードを受け取れる。

### ほかの画面へ進む

- アカウントを持つ利用者は、サインインへ進める。

### 認証済みで開く

- 認証済みの利用者がサインアップ画面を開くと、ラウンド一覧へ移動する。

### 入力の不備、重複した送信、失敗があるとき

- メールアドレス、認証コード、パスワード、またはセキュリティチェックに不備がある場合は、理由が表示され、該当する認証処理は行われない。
- 送信、確認、または登録の処理中に操作を繰り返しても、同じ認証処理は重複して行われない。
- 登録済みのメールアドレスでは、新しいアカウントの登録を開始できない。
- 認証または通信に失敗した場合は、理由が表示され、同じ段階から再試行できる。
- 登録の有無を確かめられない場合は、確認コードは送られず、理由が表示され、同じ段階から再試行できる。
- 理由が表示された後に再び送信した場合は、次の結果が出るまで、表示された理由が残る。

### 処理の途中で画面を離れたとき

- 登録の有無の確認を待つ間に画面を離れた場合は、確認コードは送られない。

## 対象外

- 登録済みアカウントの認証とパスワード再設定は、それぞれの機能で扱う。
