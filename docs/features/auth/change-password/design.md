# auth/change-password 廃止設計

## 概要

パスワード変更の画面・機能・設定項目を削除する。
旧ハッシュ専用の画面・遷移・正規化・互換分岐を残さない。

## 構成とデータの流れ

設定入口・項目・経路定数・機能固有のdomain/application/ui、パスワードIO、不要な規則・入力部品・文言を削除する。
`apps/web/src/features/settings/domain/settings-location.ts`からpassword項目を除く。
定義されないハッシュには全て同じ既存の未知項目の規則を適用し、旧ハッシュだけを判定する実装や互換テストを作らない。
直接APIで新しいパスワードを設定されても、Auth発行Hookでパスワードによる新規認証を拒否する。

## 制約と未対応

一般の未知項目の正規化は設定機能の契約であり、旧パスワード機能の互換対応として残すものではない。
パスワードハッシュは保持し、直接のパスワード更新そのものを禁止する追加の仕組みは持たない。
