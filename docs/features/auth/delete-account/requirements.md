# auth/delete-account

## 目的

サインイン済みの利用者が、自分の意思で、自分のアカウントと、アカウントに紐づく記録をAIMSから取り除けるようにする。
誤操作や、盗まれたサインインによる削除を避けるため、現在のパスワードの確認を要する。

## 要求

### アカウントを削除する

- 設定パネルの分類「アカウント」の「アカウント削除」項目から、アカウント削除の画面へ移動できる。
  項目は、メールアドレス変更・パスワード変更・サインアウトと同じ枠に並ぶ。
- 削除の前に、削除が取り消せないこと、削除される内容が伝わる。
  利用者が現在のパスワードを入力して確認の操作をするまで、削除は行われない。
- 現在のパスワードの入力欄は、表示・非表示を切り替えられ(切り替えても入力値は保たれる)、ブラウザやパスワード管理ツールが現在のパスワードとして認識できる。
  入力欄のキャプションは「現在のパスワード」である。
- 削除が完了すると、アカウントは使えなくなり、削除したメールアドレスとパスワードでサインインできない。
  この端末のサインインは終了し、サインイン画面へ移動する。サインイン画面には、削除前の画面への遷移元は付かない。
- 削除が完了した後は、ホームや点数一覧などの画面を開いてもサインイン画面へ移動し、削除した記録は表示されない。
- 削除したメールアドレスは、新しいアカウントとして改めて登録できる。
  削除前の記録は引き継がれない。
- 他の端末のサインインは、削除により使えなくなる。
  他の端末では、削除の後、認証サービスのセッションの更新と取得が拒否され、削除したメールアドレスとパスワードでサインインし直せない。
  他の端末は、アクセストークンの期限が切れた後の更新の拒否で検知され、サインイン画面へ移動する(app/navigationに従う)。
  期限が切れるまでの最大約1時間は、他の端末の期限内のアクセストークンが、認証サービス以外への通信で通りうる。
  削除後に同じメールアドレスで登録したアカウントには、その旧アクセストークンは結び付かない。
  残余リスクとして受け入れる(`docs/security.md`)。

### 削除される記録

- 削除により、利用者のプロフィール(名前)と、個人のプリセットは削除される。
- 削除により、利用者のラウンドへの参加(編集者・閲覧者のどちらも)は削除される。
- 利用者を除くと編集者がいなくなるラウンドは、ラウンド・距離・矢・それらの変更履歴の全てが削除される。
  現在、ラウンドの参加者は作成者だけであり、全てのラウンドがこれにあたる。
  進行中・完了・削除済み(論理削除)のラウンドを区別しない。
  閲覧者だけが残るラウンドも、編集者がいなくなるため削除され、閲覧者はそのラウンドを見られなくなる。
- 利用者を除いても編集者が残るラウンドは、ラウンド・距離・矢と、他の参加者の記録は残る。
  そのうち、利用者が射手として記録された矢と、その矢の変更履歴(射手の記録)、利用者が操作した変更履歴(ラウンド・距離・矢の各履歴)は匿名化される。
  匿名化された記録からは、削除した利用者を特定できず、その利用者のアカウントとも結び付かない。
  匿名化の後も、残る参加者のラウンドの表示・集計・同期は、削除の前と同じ形で成り立つ。
  利用者が閲覧者だけだったラウンドには、利用者に由来する矢や履歴がなく、参加の削除だけが行われる。
- 削除の後、利用者のアカウントに紐づく記録は、匿名化されたものを除いて残らない。
- この端末が削除の完了を知ったとき、この端末にある、その利用者の記録(端末内に保存したラウンドなどと、未送信の操作)も消える。
  消えた未送信の操作は、あとから保存されない。
  削除が完了した後に、同じメールアドレスで新しく登録した利用者や、別の利用者がサインインしても、消えた記録は表示も送信もされない。
  削除が行われなかったときは、この端末の記録は消えない。
  削除の結果が不明なときは、この端末の記録は消えず、削除が行われていた場合も、残ることがある。
  残った記録は、表示も送信もされない。
  他の端末にある記録は対象外で、その端末で次に開いたとき、サインインの失効の検知(アクセストークンの期限が切れた後)に従う。

### 現在のパスワードの確認

- 現在のパスワードが正しいときだけ、削除が行われる。
- 画面を使わない直接の呼び出しでも、サインインを維持しているだけでは、削除は拒否される。
  現在のパスワードを使った直近の本人確認(再認証)が無い呼び出しは、削除されず、アカウントも記録もそのまま残る。
  盗まれたサインイン(アクセストークン)だけでは、削除できない。
- 画面で現在のパスワードを入力して確認した直後に限り、削除できる。
  確認から時間が経ったために実行されなかったときは、削除されず、アカウントも記録もそのまま残る。
  この場合は、削除が行われなかったことが確実な失敗と同じように示され、時間が経ったことは示されない。
  入力値は保たれ、再入力せずに、もう一度実行できる。
- 削除の実行に、サービスロールなどの管理者の権限は用いない。
- 認証サービスの設定が本番で効いていることは、前提である。

### 設定パネルから開く

- 設定パネルの「アカウント削除」項目からの移動と、ハッシュ`#settings/account/delete-account`での表示は、app/settingsに従う。
- ハッシュ`#settings/account/delete-account`を付けた画面を直接開く、または再読み込みしても、設定パネルにアカウント削除の画面が表示される(入力値は残らない)。
- ブラウザの戻る・進むで、設定パネルの分類「アカウント」の表示とアカウント削除の画面の間を移動できる。
- ヘッダーに項目の名称「アカウント削除」と戻るの操作が、段階によらず表示され、戻るを押すと、削除を行わずに設定パネルの分類「アカウント」の表示へ移る。本文には分類「アカウント」へ戻る操作を置かない。
- 削除の処理中は、ヘッダーの戻るの操作は押せない。

### オフラインのとき

- 設定パネルをオフラインで開けるときは、オフラインでもアカウント削除の画面が開き、設定パネルの項目から移動できる。
- オフラインで削除を実行しても、削除は行われず、端末にも保留されず、「ネットワークに接続されていません。接続を確認してから再度お試しください。」が表示される。
- 通信が戻ると、再び実行できる。

### 不備や失敗があるとき

- 現在のパスワードが未入力のときは、セキュリティチェックの状態に関わらず、理由が表示され、削除は行われない。
- セキュリティチェックが完了する前に削除を実行しても、エラーにならず処理中の表示になり、完了すると自動で再認証が進む。
- セキュリティチェックに追加の操作が必要な間は、処理中のまま待ち、利用者が完了すると自動で再認証が進む。追加の操作が必要になった、またはチェックが失敗したことで表示されたチェック欄は、完了した後も、チェックが取り直されるまで表示されたままで(まだ操作を押していなくても同じ)、取り直されると畳まれる(取り直しで再び追加の操作が必要になれば、再び表示される)。操作が結果を返しても、チェックが取り直されなければ畳まれない。成功で画面が遷移するときは画面ごと消える。
- セキュリティチェックが失敗した、または追加の操作が無いまま一定時間完了しない場合は、失敗が表示されて処理中が解け、完了するまで削除は行われない。失敗の後に再度操作した場合も、すぐには失敗を表示せず、改めて待つ。
- 現在のパスワードが誤っているときは、削除は行われず、アカウントも記録もそのまま残り、現在のパスワードの誤りの理由が表示され、再入力できる。
  誤りが続いても、認証サービスの制限に達するまでは、毎回理由が表示される。
- 削除が行われなかったことが確実な失敗のときは、アカウントも記録もそのまま残り、この端末のサインインも維持され、理由が表示され、再試行できる。
- 認証サービスが制限の応答を返したときは、「リクエストの間隔が短すぎます。しばらくしてから再度お試しください。」が表示され、削除は行われず、時間を置いて再試行できる。
- 応答が得られなかった失敗は、結果が不明な場合を含み、区別せず「通信エラーが発生しました。しばらくしてから再度お試しください。」を表示する。
  結果が不明なとき、削除が行われていることがあり、その場合、再試行は、サインインが失効しているため、サインイン画面へ移動する。
  このとき、この端末の記録は消えず、残ることがある(「削除される記録」に従う)。
- 削除は、アカウントと記録の一部だけが残る状態で終わらない。
  完了するか、全く行われないかのどちらかである。
- 削除の処理中に操作を繰り返しても、同じ削除は重複して行われない。

### サインインしていないとき、サインインが切れたとき

- 未認証で、ハッシュ`#settings/account/delete-account`を付けた画面を開くと、サインイン画面へ移動し、開こうとした画面がハッシュを含めて遷移元として付く。
  サインインすると、その画面が、設定パネルにアカウント削除の画面を開いた状態で表示される。
- 表示中にサインインが切れたときは、サインイン画面へ移動する。
- サインアウトした後、ブラウザの戻るでアカウント削除の画面を開こうとしても、サインイン画面へ移動する。
- 画面の枠を保存した後でも、未認証または期限切れで開くと、サインイン画面へ移動する。

### 処理の途中で画面を離れたとき

- 削除の応答を待つ間に別の画面へ離れた(ブラウザの戻る・進むでハッシュが変わり、設定パネルの別の表示へ移った、または設定パネルが閉じたときを含む)利用者には、その応答による表示は起きない。
  削除自体は、応答が成功なら行われる。

## 対象外

- アカウントの一時停止、削除の取り消し・猶予期間、削除後の復元。
- 削除前の記録の書き出し(エクスポート)。
- Google認証で作ったアカウントの削除(Google認証は未実装)。
- 匿名化された記録の表示(現在、射手と操作した利用者は画面に表示されない)。
- 編集者が残らないラウンドの、残る閲覧者への事前の通知。
- 現在のパスワードの総当たりの抑止の強さ。認証サービスの制限に委ね、アプリ側では再試行の回数を制限しない。盗まれたサインインの保持者による推測は、残余リスクとして受け入れる(`docs/security.md`)。
- メールの認証コードによる本人確認。
- 現在のパスワードを忘れた利用者の削除(パスワード再設定は auth/password-reset)。
- 削除の履歴の記録と通知メール。
- 端末へのオフライン中の削除の保留。
- メールアドレス変更・パスワード変更・サインアウトの変更。
