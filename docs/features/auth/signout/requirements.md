# auth/signout

## 目的

利用者が、誤操作を避けながら、この端末でのサインインを終えられるようにする。

## 要求

### サインアウトする

- 確認ダイアログでサインアウトを確認すると、この端末のサインインが終了し、サインイン画面へ移動する。
- どの画面からサインアウトしても、サインイン画面にサインアウト前の画面への遷移元は付かない。
- オフラインでも、この端末のサインインは終了し、オフライン画面が表示される。

### 確認ダイアログを閉じる

- 確認ダイアログは、キャンセル、ダイアログの外のクリック、Escキーのいずれでも、サインアウトせずに閉じる。
- サインアウトの完了を待つ間は、キャンセル、確認、ダイアログの外のクリック、Escキーのいずれでもダイアログは閉じず、サインアウトは重複して行われない。

### 失敗したとき

- サインアウトに失敗した場合は、ダイアログに理由が表示され、再度確認できる。

## 対象外

- サインアウトボタンと確認ダイアログを開くまでの導線は、app/navigationで扱う。
- 他の端末のサインインは終了しない。
