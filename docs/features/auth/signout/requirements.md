# auth/signout

## 目的

利用者が、誤操作を避けながら、この端末でのサインインを終えられるようにする。

## 要求

### サインアウトする

- 確認ダイアログでサインアウトを確認し、この端末のサインインを終えられたときは、サインイン画面へ移動する。
- どの画面からサインアウトしても、サインイン画面にサインアウト前の画面への遷移元は付かない。
- サインアウトした後は、サインイン画面からラウンド一覧へ戻されず、ラウンドの画面を開くとサインイン画面へ移動する。
- オフラインでも、この端末のサインインを終えられたときは、オフライン画面が表示される。

### 確認ダイアログを閉じる

- 確認ダイアログは、キャンセル、ダイアログの外のクリック、Escキーのいずれでも、サインアウトせずに閉じる。
- サインアウトの完了を待つ間は、キャンセル、確認、ダイアログの外のクリック、Escキーのいずれでもダイアログは閉じず、サインアウトは重複して行われない。

### 失敗したとき

- この端末のサインインを終えられなかった場合は、サインイン画面へ移動せず、ダイアログに理由が表示され、再度確認できる。
- 認証サービスが失敗を返しても、この端末のサインインを終えられた場合は、失敗は表示されず、サインイン画面へ移動する。

### 処理の途中で画面を離れたとき

- サインアウトの完了を待つ間に画面を離れた場合は、離れた後にサインイン画面へ移動しない。

## 対象外

- サインアウトボタンと確認ダイアログを開くまでの導線は、app/navigationで扱う。
- 他の端末のサインインは終了しない。
