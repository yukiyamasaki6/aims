# auth/signout

| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| signout-01 | サインアウト確認ダイアログでサインアウトが成功する | 確認ボタンをクリックする | サインアウトされる<br>/へ遷移する |
| signout-02 | サインアウト確認ダイアログ | キャンセルボタンをクリックする | ダイアログが閉じられる |
| signout-03 | サインアウト確認ダイアログ | 背景をクリックする | ダイアログが閉じられる |
| signout-04 | サインアウト確認ダイアログでサインアウトの完了が遅い | 確認ボタンをクリックする | ダイアログが開いたままになる<br>キャンセルボタン・確認ボタン・背景のクリックが無効になる |
| signout-05 | サインアウト確認ダイアログでオフライン | 確認ボタンをクリックする | サインアウトされる<br>/へ遷移する |
| signout-06 | サインアウト確認ダイアログでサインアウトが失敗する | 確認ボタンをクリックする | エラーメッセージが表示される<br>確認ボタンが再度有効になる |
