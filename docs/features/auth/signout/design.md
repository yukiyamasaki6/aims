# auth/signout 設計

## 概要

左パネルのサインアウトボタンから確認ダイアログを開き、確認ボタンで実行する。
クライアントで`supabase.auth.signOut({ scope: "local" })`を呼び、この端末のセッションだけを終了する。
成功すると`SIGNED_OUT`を`SessionGuard`が検知して`/signin`へ遷移する（`app/navigation`）。サインアウト処理自身は遷移しない。
`SIGNED_OUT`の遷移は、同一タブの明示サインアウトでは遷移元を付けない（`markExplicitSignOut`をサインアウトの前に呼び、失敗で`clearExplicitSignOut`する。signout-07）。失敗したらダイアログを開いたままエラーを表示し、再試行できる。
ダイアログを開くところまでは`app/navigation`の担当で、この文書は確認ダイアログ以降を扱う。

## 画面と状態

| 状態 | 表示 | 次の状態 | 要求 |
| --- | --- | --- | --- |
| 確認中 | 説明文、キャンセル、確認 | キャンセル・背景クリックで閉じる、確認でサインアウト中 | signout-02, 03 |
| サインアウト中 | 確認ボタンにスピナー。キャンセル・確認・背景クリックは無効 | 成功で`/signin`へ遷移、失敗でサインアウト失敗 | signout-01, 07, 04, 05 |
| サインアウト失敗 | ダイアログ内にエラー。ボタンは操作可能に戻る | 再試行、またはキャンセル | signout-06 |

- オフラインでも成功として扱い、`/signin`へ遷移する。オフラインの`/signin`はService Workerが`/offline`を返すため、観測できるのはオフライン画面である(signout-05)。`SIGNED_OUT`はオフラインでも遷移させる。

## 構成とデータの流れ

- `src/app/(main)/left-panel.tsx`: サインアウトボタンとダイアログを持つ。
- `src/components/ui/confirm-dialog.tsx`: `BlockingConfirmDialog`。二重送信の防止、送信中の無効化、エラー表示、再試行を担う。`rounds/delete`と共通である。
- `src/app/(main)/sign-out.ts`: `signOut`を呼び、成否を判定する。
- `src/features/auth/local-identity.ts`: 端末の識別情報を持つ。

契約は次のとおりである。

- 成否は、通信の成否でなく、端末の識別情報が消えたかで判断する。
- supabase-jsの`signOut`は、`scope`が`others`以外なら、サーバーがエラーでもローカルのセッションを削除する。そのためオフラインでも成功にできる。
- 識別情報の更新元は`onAuthStateChange`だけである。
- 識別情報が残った場合は、通信エラーの文言を表示する。

## 設計判断

| 判断 | 理由 | 見直す条件 |
| --- | --- | --- |
| クライアントの`signOut()`で行い、遷移はセッション喪失の検知に任せる | Server Actionのリダイレクトが遷移を横取りするレースを避けるため、Server Actionをやめた。詳細: #363。サインアウトの経路でも遷移させると検知の不具合が隠れるため1経路にする | レースを避けられる方式が出たとき |
| `scope: "local"`でこの端末のセッションだけを終了する | 既定の`global`は全端末のセッションを無効にするため | 全端末のサインアウトを提供するとき |
| 成否を識別情報の有無で判断する | オフラインでエラーが画面に残る不具合があり、`getUser`に基づく確認と通信の成否での判断をやめた。詳細: #502 | supabase-jsの`signOut`の挙動が変わったとき |
| 識別情報の更新を`onAuthStateChange`だけにする | オフラインでも利用者を識別するため、更新元を一本化する | 識別情報の更新元を増やす必要が出たとき |
| 確認ダイアログを挟む | 誤操作でのサインアウトを防ぐため | 取り消せるサインアウトにするとき |
| 確認ダイアログを`BlockingConfirmDialog`に共通化する | 削除確認と同じ構造で、重複を除くため | 画面ごとに挙動が分かれるとき |

## 制約と未対応

- 端末の識別情報が残った場合の失敗は、通信エラーの文言で表示し、原因を区別しない。
