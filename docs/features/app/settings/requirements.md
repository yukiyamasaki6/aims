# app/settings

## 目的

サインイン済みの利用者が、今の画面を離れずに、アカウント設定などを一か所で確認・変更できるようにする。
設定の中の分類と項目をURLのハッシュで指定して、同じ表示を開き直せるようにする。

## 要求

### 設定パネルを開く

- レフトパネル/ドロワーの「設定」項目を押すと、今の画面の上に設定パネルが開き、分類「アカウント」が表示され、URLのハッシュが`#settings/account`になる。項目は、ホーム・点数一覧・詳細・作成のどの画面でも表示される。
- 設定パネルを開いても、背景の画面は別の画面へ移らず、読み込み直されない。設定パネルを閉じると、開く前の画面が表示される。
- 設定パネルが開いている間は、「設定」項目が現在のビューとして識別でき、支援技術に現在のビューとして伝わる。「ホーム」「点数一覧」項目は現在のビューにならない。
- 幅768px未満でドロワーが展開されているときに「設定」項目を押すと、ドロワーが格納され、設定パネルが開く。幅768px以上では、レフトパネルの開閉は変わらない(閉じない)。
- 「設定」項目はキーボードで操作できる。
- ホーム・点数一覧・詳細・作成の画面を、ハッシュ`#settings/account`、`#settings/account/email`、`#settings/account/password`、`#settings/account/delete-account`のいずれかを付けて開く、または再読み込みすると、その画面の上に設定パネルが開き、ハッシュが指す分類または項目の画面が表示される(項目の画面の入力値と途中の経過は残らない)。
- ハッシュが`#settings`のとき、または`#settings/`で始まり存在しない分類・項目を指すときは、`#settings/account`として設定パネルが開き、ブラウザの履歴を増やさずにハッシュが`#settings/account`になる。
- `#settings`でも`#settings/`で始まるものでもないハッシュ(`#settingsfoo`など)は、設定パネルを開かず、ハッシュも変えない。
- サインイン画面・サインアップ画面・パスワード再設定画面・紹介画面・オフラインのページ・見つからない旨の画面では、ハッシュが`#settings`または`#settings/`で始まるものでも、設定パネルは開かない。

### 設定パネルの中を使う

- 設定パネルには、タイトル「設定」と、閉じる操作と、分類の一覧が、分類・項目の画面によらず常に表示される。
- 分類の一覧は「アカウント」だけを持ち、選んでいる分類が識別でき、支援技術に伝わる。
- 分類の一覧で分類を選ぶと、その分類の表示へ移り、ハッシュがその分類を指す。
- 幅768px未満で分類の一覧が設定パネルの上に横並びのタブとして表示されるときは、各タブの幅はその分類の名称の文字の幅に合い、分類が1つでも横いっぱいには広がらない。
- タブの並びが設定パネルの幅からはみ出すときは、並びを横にスクロールして、すべての分類を見て選べる。
- 分類「アカウント」の表示には、メールアドレス変更とパスワード変更とアカウント削除とサインアウトがあり、本文に分類の見出しは表示されない。
- メールアドレス変更とパスワード変更とアカウント削除とサインアウトは、見出しを持たない境界線のある1つの枠にまとめられ、同じ大きさの行として並ぶ。
  行の間には区切り線がある。
- 「メールアドレス変更」項目を押すと、設定パネルの中にメールアドレス変更の画面が表示され、ハッシュが`#settings/account/email`になる。画面の要求は、auth/change-emailに従う。
- 「パスワード変更」項目を押すと、設定パネルの中にパスワード変更の画面が表示され、ハッシュが`#settings/account/password`になる。画面の要求は、auth/change-passwordに従う。
- 「アカウント削除」項目を押すと、設定パネルの中にアカウント削除の画面が表示され、ハッシュが`#settings/account/delete-account`になる。画面の要求は、auth/delete-accountに従う。
- メールアドレス変更・パスワード変更・アカウント削除の画面には、ヘッダーに項目の名称と戻るの操作があり、戻るを押すと分類「アカウント」の表示へ移り、ハッシュが`#settings/account`になる。
- サインアウトの確認、実行、失敗の表示、完了後の遷移は、auth/signoutに従う。
- サインアウトの確認ダイアログが開いている間は、Escキーとダイアログの外側の押下で確認ダイアログだけが閉じ、設定パネルは閉じない。
- レフトパネル/ドロワーにサインアウトボタンは表示されない。
- 設定パネルの閉じる操作、分類の一覧、サインアウトと「メールアドレス変更」「パスワード変更」「アカウント削除」項目、各項目の画面の戻るは、キーボードで操作できる。
- 設定パネルが開いている間は、背景の画面を操作できず、キーボードのフォーカスも背景の画面へ届かない。
- 設定パネルは、支援技術に、タイトル「設定」の対話の領域として伝わる。

### ブラウザの戻る・進むで移る

- 設定パネルを開く操作と、設定パネルの中の移動(分類の選択、項目を押す、項目の画面の戻る)は、それぞれブラウザの履歴に1つずつ積まれる。
- ブラウザの戻るを押すと、1つ前の設定パネルの表示(分類または項目の画面)へ移る。
- 画面の読み込みより後に開いた設定パネル(「設定」項目で開いたときなど)は、開いた最初の表示で戻るを押すと閉じ、開く前の画面が表示される。
- 画面の読み込み時に開いた設定パネル(ハッシュ付きのURLを直接開いた、再読み込みした、サインイン後に遷移元へ戻ったとき)は、読み込み時の表示で戻るを押すと、その画面の読み込みより前の履歴へ移る。
- ブラウザの進むを押すと、戻る前の設定パネルの表示が開く。

### 設定パネルを閉じる

- 閉じる操作、Escキー、または幅768px以上で設定パネルの外側を押すと、設定パネルが閉じる。
- 幅768px以上では、設定パネルの外側に背景の画面が見える。幅768px未満では、設定パネルが画面全体を覆い、背景の画面は見えない。
- 幅768px以上で、設定パネルの外側にあるレフトパネルの「ホーム」「点数一覧」項目を押すと、設定パネルが閉じるだけで、その画面へは移らない。
- 画面の読み込みより後に開いた設定パネルを閉じると、ブラウザの履歴は設定パネルを開く前の位置へ戻り、開く前の画面が表示される。設定パネルの中で何度移動していても同じである。
- 画面の読み込み時に開いた設定パネル(ハッシュ付きのURLを直接開いた、再読み込みした、サインイン後に遷移元へ戻ったとき)を閉じると、ブラウザの履歴は読み込み時の位置まで戻ってハッシュが外れ、背景の画面が表示される。設定パネルの中で何度移動していても同じである。
- 画面の読み込み時に開いた設定パネルを閉じた後にブラウザの戻るを押すと、その画面の読み込みより前の履歴へ移り、読み込みより後に設定パネルの中で移った表示は開かない。
- 画面の読み込みより後に開いた設定パネルを閉じると、キーボードのフォーカスは、幅768px以上でレフトパネルが開いているときは「設定」項目へ、幅768px以上でレフトパネルが閉じているときと幅768px未満ではヘッダーのメニューボタンへ戻る。レフトパネル/ドロワーの開閉は変わらない。
- 画面の読み込み時に開いた設定パネルを閉じると、キーボードのフォーカスは背景の画面の先頭へ移る。

### 項目の処理の実行中

- メールアドレス変更・パスワード変更・アカウント削除の処理の実行中は、閉じる操作、Escキー、設定パネルの外側の押下、分類の切り替え、項目の画面の戻るのいずれも受け付けず、設定パネルは実行中の表示のままである。
- 実行中も、ブラウザの戻る・進むは受け付け、ハッシュが変わるとそのハッシュの表示へ移る(ハッシュが外れると設定パネルが閉じる)。実行中だった処理は、各機能の「処理の途中で画面を離れたとき」に従い、応答による表示は起きず、処理自体は応答が成功なら行われる。

### サインインしていないとき、サインインが切れたとき

- 未認証で、ハッシュ`#settings`、または`#settings/`で始まるハッシュを付けてホーム・点数一覧・詳細・作成の画面を開くと、サインイン画面へ移動し、開こうとした画面がハッシュを含めて遷移元として付く。サインインすると、その画面が、ハッシュが指す表示の設定パネルを開いた状態で表示される(`#settings`や存在しない分類・項目は、「設定パネルを開く」に従い`#settings/account`として開く)。
- 設定パネルの表示中にサインインが切れたときは、サインイン画面へ移動し、開いていた画面が設定パネルのハッシュを含めて遷移元として付く。サインインすると、その画面が、同じ表示の設定パネルを開いた状態で表示される。
- サインアウトした後、ブラウザの戻るで設定パネルを開いていた画面を開こうとしても、サインイン画面へ移動する。

### オフラインのとき

- 背景の画面がオフラインで開けるときは、オフラインでも設定パネルを開ける。サインインしていない状態で画面の枠を保存した後にサインインした場合も同じである。
- オフラインの設定パネルで、サインアウトを操作でき、「メールアドレス変更」項目と「パスワード変更」項目と「アカウント削除」項目から、それぞれの画面へ移動できる。各画面のオフラインでの扱いは、auth/change-email、auth/change-password、auth/delete-accountに従う。

## 対象外

- 個別の設定項目(テーマ、デフォルト入力設定、ログ収集など)の実装は扱わない。設定値の保存は扱わない。
- 分類「一般」(`#settings`)は、一般の設定項目を加えるときに分類の一覧へ加え、`#settings`をその分類とする。
- 設定項目が通信を要するときの、オフラインでの操作不可の表示と、オンライン復帰時の扱いは、項目を加えるときの要求で定める(メールアドレス変更はauth/change-email、パスワード変更はauth/change-password、アカウント削除はauth/delete-accountで扱う)。
- サインアウトの確認、実行、失敗の表示は、auth/signoutで扱う。
- 画面の枠をオフラインで保存する仕組みは、app/offline-pwaで扱う。
