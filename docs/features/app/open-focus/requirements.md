# app/open-focus

## 目的

利用者が、フィルターパネルやダイアログを開いただけで、キーボードが勝手に出て画面が動くことがないようにする。

## 要求

### 開く

- フィルターパネルと、共通のダイアログ部品を使うすべてのダイアログを、タッチ・マウス・キーボードのどれで開いても、開いた直後に入力欄はフォーカスを持たない。
- 開いた直後のフォーカスは、開いたもの自体(パネルの領域、ダイアログのポップアップ)にあり、Tabで中の最初の操作へ進める。
- 開閉で一覧・画面のスクロール位置は動かない。
- 開いたことは、名前付きの領域・ダイアログとして支援技術に伝わる。

### 開いた後の入力

- 利用者が入力欄をタップ・Tab・Enterで選んだときは、通常どおり入力欄がフォーカスを持つ。
- 閉じた後のフォーカスの戻り先、横長の検索後に「検索」へフォーカスが残ること、向きの変更でフォーカスが動かないことは変わらない。

## 対象外

- ログインフォームのEnterでの欄の移動、ドロップダウンメニュー(入力欄を含まない)。
- 認証系と設定内の画面の初期表示(再現しなかったため変更しない)。
