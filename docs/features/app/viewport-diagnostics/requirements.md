# app/viewport-diagnostics

## 目的

利用者が、画面の表示領域に不具合があるとき、案内に従って測定値を画面に出し、報告できるようにする。

## 要求

### 設定で切り替える

- 設定画面に「表示領域の診断」の切り替えがあり、初期は無効である。
- 有効にすると、全画面(サインイン前の画面を含む)に表示領域の測定値が表示され、無効にすると消える。
- 切り替えはキーボードで操作できる。

### 設定を保つ

- 有効・無効は端末に保存され、再読み込み、アプリの再起動、サインアウト・サインイン後も保たれる。
- オフラインでも切り替えられる。

### 無効のとき

- 測定値を表示せず、画面の表示と挙動は診断のない場合と同じである。

## 対象外

- 測定値の保存と送信は扱わない。
- 測定値の意味づけは扱わない。
- 保存先が使えない環境での保持は扱わない。
