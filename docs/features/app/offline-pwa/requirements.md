# app/offline-pwa

## 目的

利用者が、AIMSをアプリとして端末に入れて起動し、通信できないときもラウンドの画面を開けて、新しい版が公開されたときは、使っている画面を妨げられずに新しい版へ移れるようにする。

## 要求

### アプリとして入れて起動する

- 紹介画面を開くと、ブラウザからアプリとしてインストールできる。
- サインインしていなくても、iOSのホーム画面に追加するアイコンの画像が取得できる。
- 初めてアプリを開くと、画面の表示に使うファイルと、ラウンド一覧、ラウンドの作成、ラウンドの詳細の画面の枠と、オフラインのページが端末に保存される。
- サインイン済みでアプリを起動すると、ラウンド一覧が表示される。
- サインインしていない状態でアプリを起動すると、サインイン画面へ移動する。

### 通信を待たずに開く

- 画面の枠を保存した後にラウンドの詳細を開くと、内容の取得を待たずに、詳細の枠と読み込み中の表示が出る。
- 画面の枠を保存した後に開いたラウンドの詳細は、内容の取得が終わると、内容が表示される。

### オフラインで開く

- オフラインで、ラウンドの画面以外(紹介画面など)を開くと、オフラインのページが表示される。
- オフラインのページでAIMSロゴを押すと、紹介画面へ移動する。
- 入力中のラウンドが端末に無いときに、オフラインでラウンド一覧を開くと、一覧の枠と「ネットワークに接続されていません」が表示され、「まだラウンドがありません。」と、入力中と「過去履歴」の見出しは表示されない。
- プリセットを端末に保存していないときに、オフラインでラウンドの作成を開くと、作成の枠と「ネットワークに接続されていません」が表示される。
- 端末にオフラインで開ける内容がないラウンドを、オフラインで開くと、詳細の枠と「ネットワークに接続されていません」が表示される。
- サインインしていない状態で画面の枠を保存した後にサインインした場合も、オフラインでラウンド一覧を開くと、サインイン画面は表示されず、一覧の枠と「ネットワークに接続されていません」が表示される。

### オンラインに戻ったとき

- 入力中のラウンドが端末に無いときに、オフラインで開いたラウンド一覧に「ネットワークに接続されていません」が表示されているときに、オンラインに戻ると、一覧の内容が表示され、「ネットワークに接続されていません」は表示されなくなる。
- プリセットを端末に保存していないときに、オフラインで開いたラウンドの作成に「ネットワークに接続されていません」が表示されているときに、オンラインに戻ると、プリセット一覧が表示され、「ネットワークに接続されていません」は表示されなくなる。
- 端末にオフラインで開ける内容がないラウンドを、オフラインで開いて「ネットワークに接続されていません」が表示されているときに、オンラインに戻ると、ラウンドの内容が表示され、「ネットワークに接続されていません」は表示されなくなる。

### 新しい版が公開されたとき

- 使っている間に新しい版が公開されても、表示中の画面は読み込み直されず、古い版のまま使える。
- 画面を開いた後に新しい版が公開されたときは、他の画面へ移ると新しい版が端末に届き、その移動では古い版のまま表示される。
- 新しい版が端末に届いているときに、リンクを押して他の画面へ移ると、移った先は、古い版の画面を挟まずに新しい版で表示される。
- 新しい版が端末に届いているときは、オフラインでも、リンクを押して他の画面へ移ると、移った先が新しい版の枠で表示される。

### 新しい版へ切り替えられないとき

- 新しい版が端末に届いていても、画面を開いてから切り替えの準備が済む前、切り替えが進まないとき、または端末への記録の保存が終わらないときにリンクを押すと、移った先は古い版で表示され、操作できる。
- 古い版のまま移った後も、次にリンクを押して移るときは、改めて新しい版へ切り替える。

### サインインしていないとき、サインインが切れたとき

- 画面の枠を保存した後でも、サインインしていない、またはサインインが切れた状態でラウンドの画面を開くと、サインイン画面へ移動する。

## 対象外

- 画面の枠を保存する前のオフラインの表示は扱わない。
- 端末にオフラインで開ける内容があるラウンドの詳細の表示は、rounds/detailで扱う。
- オフラインの一覧に入力中のラウンドを表示することは、rounds/historyで扱う。
- 端末に保存したプリセットと的の、オフラインでの表示は、rounds/startで扱う。
- サインインしていないとき、サインインが切れたときの移動の判定と、画面を開いている間の失効の検知は、app/navigationで扱う。
- 記録や変更の送信と同期は、rounds/syncで扱う。
- 新しい版が公開されたことの通知と、更新を促す表示は扱わない。
- リンク以外の方法(ブラウザの戻る・進むなど)で移るとき、または画面を移らずに使い続けるときに、新しい版へ切り替えることは扱わない。
- 回線につながっていても外へ通信できないときに、通信が戻ったことを検知して自動で表示し直すことは扱わない(再試行で表示し直す)。
