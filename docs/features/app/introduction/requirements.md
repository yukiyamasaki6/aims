# app/introduction

## 目的

AIMSを使ったことがない人が、紹介画面で、アーチェリーの練習や試合でやりたいことをAIMSで実現できるかを判断し、実現できると期待できたら、そのまま使い始められるようにする。

## 要求

### やりたいことが実現できるかを知る

- 紹介画面(`/`)を開くと、サインインの有無によらず、アプリの価値を表すキャッチが表示される。
- 紹介画面には、利用者の主な目的ごとに、AIMSで今実現できることが表示される。目的は、一射ずつの点数の記録、自分のラウンドの形式での記録、過去の記録の見返しを含む。
- 紹介画面には、対応する的の種類とラウンドの形式を自分で組めること、通信が切れても記録できることが表示される。
- 紹介画面は、キャッチを含む文と図のどちらでも、今使えない機能を今使える機能として示さない。
- 紹介画面の内容は、サインインせずに、ページを開くだけで読める。
- 紹介画面の内容は、利用の条件(アカウント登録の要否、ゲスト利用の有無)に触れず、これらの条件が変わっても変わらない。

### 記録を始める

- 紹介画面の本文の、文言「記録を始める」のボタンを押すと、サインイン画面へ移動する。
- 紹介画面を開いて最初に表示される範囲で、サインインへ進む操作を行える。
- 紹介画面の末尾まで読み進めた後も、上へ戻らずにサインインへ進む操作を行える。
- 認証済みの利用者は、紹介画面の「記録を始める」を押すと、移動先の画面からホーム(サインインの後の既定の行き先)へ移動する。

### 支援技術とキーボードで読む

- 紹介画面の各目的の紹介は見出しで区切られ、支援技術で見出しから各紹介へ移動できる。
- 「記録を始める」は、キーボードで操作でき、支援技術に用途の分かる名前で伝わる。
- 紹介の図や画像が伝える内容は、文字でも伝わる。

### 機能や画面が変わった後に読む

- 紹介した機能の、利用者から見える振る舞いが変わったり削除されたりした後も、紹介画面の記述は今の振る舞いと食い違わない。
- 画面の配置や見た目だけが変わった後も、紹介画面の図や画像は誤りにならない。

## 対象外

- できることの網羅と、使い方(操作の手順・チュートリアル)の説明。
- 紹介画面上での実際の操作の体験。
- ゲスト利用の採否(別機能の候補。紹介の内容は登録の要否に依存しないため、採否によって紹介は変わらない)。
- 既存の利用者向けの専用の入口(「記録を始める」でサインイン画面へ進める)。
- オフラインのページへのヘッダーの追加。
- 検索エンジン向けの最適化、更新履歴・ニュースの発信、外部からの流入導線。
- 不具合報告・要望の受付、利用規約・プライバシーポリシーの掲載。
- 料金・プランの紹介。
- 日本語以外での紹介。
- 紹介画面の閲覧の計測・ログ収集。
- オフラインでの紹介画面の表示(オフラインのページを表示する。app/offline-pwaで扱う)。
- AIMSロゴを押したときの紹介画面への移動(app/navigationで扱う)。
