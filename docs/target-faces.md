## 3つ目（マルチスポット）のスポット中心座標

原点(0, 0)は「全体（的紙・3つの的の幾何中心）」。縦3スポットは中央の的の中心、三角3スポットは3つの的の中心が成す正三角形の重心（外心）を原点とする。X軸は右が正、Y軸は上が正。

`d`を隣接する的の中心間距離（cm）とすると、

- **縦3スポット**: 上(0, d)・中(0, 0)・下(0, -d)。
- **三角3スポット**（上1つ・下2つ）: 正三角形の重心から頂点までの距離・底辺までの距離の公式で求める。上頂点(0, d/√3)、下2点(±d/2, -d/(2√3))。

`d`自体は各的のリング半径から計算した値ではなく、実測の的中心間距離。

| 的 | d (cm) |
| :--- | :--- |
| Indoor 40cm 縦3スポット | 22.00 |
| Indoor 60cm 縦3スポット | 32.00 |
| Field 20cm 縦3スポット | 22.00 |
| Indoor 40cm 三角3スポット | 22.00 |
| Indoor 60cm 三角3スポット | 32.00 |

計算結果（cm、小数第2位まで）:

| 的 | 上/中央 | 下左 | 下右 |
| :--- | :--- | :--- | :--- |
| Indoor 40cm 縦3スポット | (0, +22.00) | 中(0, 0) | 下(0, -22.00) |
| Indoor 60cm 縦3スポット | (0, +32.00) | 中(0, 0) | 下(0, -32.00) |
| Field 20cm 縦3スポット | (0, +22.00) | 中(0, 0) | 下(0, -22.00) |
| Indoor 40cm 三角3スポット | (0, +12.70) | (-11.00, -6.35) | (+11.00, -6.35) |
