# Requirements Definition (要件定義)

画面ごとの機能概要は`feature-map.md`、画面間の遷移は`screen-flow.md`を参照。

## 要件定義表の書式

- `状態`: その行が属する状態（`-`は使わず具体的に）
- `条件`: 結果を起こすために必要な追加条件（無ければ`-`）
- `行動`: ユーザーが行う操作（不変条件の行では`-`）
- `結果`: システムが起こす結果（`状態`・`条件`・`行動`が同じ結果は1行にまとめる）
- `実装`: 〇（テスト済み）／△（未テスト）／⚠（未実装）

## `/` 紹介画面

| 状態 | 条件 | 行動 | 結果 | 実装 |
| :--- | :--- | :--- | :--- | :---: |
| 初期アクセス | 未認証 | - | 紹介画面を表示する | 〇 |
| 初期アクセス | 認証済み | - | /roundsへ遷移 | 〇 |
| 紹介画面 | - | - | アプリ名と説明文を表示する | 〇 |
| 紹介画面 | - | 開始ボタンをクリック | /signupへ遷移 | 〇 |

## `/signin` サインイン画面

| 状態 | 条件 | 行動 | 結果 | 実装 |
| :--- | :--- | :--- | :--- | :---: |
| 初期アクセス | 未認証 | - | サインイン画面を表示する | 〇 |
| 初期アクセス | 認証済み | - | /roundsへ遷移 | 〇 |
| サインイン画面 | - | 「パスワードをお忘れですか」リンクをクリック | /reset-passwordへ遷移 | 〇 |
| サインイン画面 | - | 「サインアップ」リンクをクリック | /signupへ遷移 | 〇 |
| サインイン画面 | メールアドレス未入力 | サインインボタンをクリック | メールアドレスの未入力エラーを表示する | 〇 |
| サインイン画面 | メールアドレスの形式が不正 | サインインボタンをクリック | メールアドレスの形式エラーを表示する | 〇 |
| サインイン画面 | パスワード未入力 | サインインボタンをクリック | パスワードの未入力エラーを表示する | 〇 |
| サインイン画面 | captcha未完了 | サインインボタンをクリック | captcha未完了のエラーを表示する | 〇 |
| サインイン画面 | エラーが表示されている | サインインボタンをクリック | 表示中のエラーを消す<br>新しいエラーを表示する | 〇 |
| サインイン画面 | - | サインインボタンをクリック | 認証リクエストを送信する | 〇 |
| サインイン中 | - | - | サインインボタンを無効にする | 〇 |
| サインイン中 | - | 認証が失敗する | エラーメッセージを表示する<br>サインインボタンを再度有効にする<br>captchaトークンをリセットする | 〇 |
| サインイン中 | - | 通信エラーが発生する | エラーメッセージを表示する<br>サインインボタンを再度有効にする<br>captchaトークンをリセットする | 〇 |
| サインイン中 | - | 認証が成功する | /roundsへ遷移する | 〇 |
