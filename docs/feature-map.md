# Feature Map (機能配置図)

実装タイミングはroadmap.mdを参照。

| 画面 | 概要 | 実装状況 |
| :--- | :--- | :--- |
| `/`<br>ルート | 認証状態に応じて`/rounds`または`/signin`へリダイレクト | ○ |
| `/signin`<br>サインイン画面 | サインイン。`/signup`への導線を持つ | ○ |
| `/signup`<br>サインアップ画面 | メール送信→認証コード入力→パスワード設定の3ステップ（同一URL内） | ○ |
| `/reset-password`<br>パスワード再設定画面 | メール送信→認証コード入力→新パスワード設定の3ステップ（同一URL内。`/signup`と同じパターン） | ○ |
| LeftPanel | `(main)`配下の全画面に表示するグローバルナビゲーション（`(auth)`配下には無い）。結合ボタンから開閉し、PCは常時展開・モバイルはドロワー。上から: 自分 → 所属チーム一覧（行右端のメニューから`[teamId]`(チーム管理画面)へ）→「チーム参加・作成」ボタン（`/teams`へ）→ 設定・規約・要望へのリンク → サインアウト。開閉はどの画面でも共通の状態変化であり、画面遷移としては扱わない | ○ |
| `/rounds`<br>ラウンド一覧（個人） | 個人コンテキストのラウンド一覧（履歴） | ○ |
| └── RoundCard | 一覧の各行。日付・ラウンド名・合計点・X数を表示し、独立したサマリー画面の代わりを兼ねる | ○ |
| `/rounds/trend`<br>推移（個人） | 個人コンテキストの得点推移グラフ | ✕ |
| `/rounds/stats`<br>統計分析（個人） | 個人コンテキストの統計分析 | ✕ |
| `/rounds/ai`<br>AI分析（個人） | 個人コンテキストのAI分析 | ✕ |
| `/rounds/new`<br>ラウンド作成 | 定型プリセットまたはカスタム（空で開始）を選ぶだけの入口。選択と同時に`rounds`を作成し`/rounds/[id]`へ遷移する。ラウンド名・実施日・種別・弓種・距離構成の入力は行わない（個人・チーム両コンテキストで共用） | ○ |
| └── RoundPresetSelect | 定型プリセット選択（グローバル/自分の過去の構成）＋「カスタム（空で開始）」 | ○ |
| `/rounds/[id]`<br>ラウンド入力・閲覧の統合画面 | コンテキストに依存しない共通の着地点。独立したサマリー専用画面は設けず、この画面がそのまま閲覧・サマリーを兼ねる。連続入力の速度を優先し、確定後にページ遷移を挟まず入力を即座に反映する。ラウンド名・実施日・種別・弓種・距離構成（追加/削除・的の選択）の入力・編集もこの画面でのみ行う | ○ |
| └── RoundConfigPanel | ラウンド名・実施日・種別・弓種・距離構成（追加/削除）・プリセット保存ボタンをまとめた折りたたみ式編集区画（普段は要約1行、タップで展開）。距離ごとの総エンド数・エンドあたりの本数・的選択は距離行ごとに個別に折りたためる。総エンド数・エンドあたりの本数は`shots`が1件でも入力された距離では編集不可（削除して作り直す）。距離削除時に`shots`が存在する場合は確認を挟むが、削除自体は`shots.distance_id`の`on delete cascade`で完結する | ○ |
| └── CurrentEndHeader | 現在の距離・エンド・累計、X/10カウントを表示 | ○ |
| └── ScoreSheet | 入力済みエンドの小計一覧（全距離分） | ○ |
| └── ScoreKeypad | X, 10〜1, Mの入力パネル。未入力がある間のみ表示し、入力は即座に`shots`へ反映される | ○ |
| `/teams/[teamId]/rounds`<br>ラウンド一覧（チーム） | チームコンテキストのラウンド一覧（履歴） | ✕ |
| `/teams/[teamId]/rounds/trend`<br>推移（チーム） | チームコンテキストの得点推移グラフ | ✕ |
| `/teams/[teamId]/rounds/ranking`<br>ランキング（チーム） | チームコンテキストのランキング | ✕ |
| `/teams/[teamId]/rounds/team-match`<br>団体戦（チーム） | チームコンテキストの団体戦機能 | ✕ |
| `/teams/[teamId]/rounds/stats`<br>統計分析（チーム） | チームコンテキストの統計分析 | ✕ |
| `/teams/[teamId]/rounds/ai`<br>AI分析（チーム） | チームコンテキストのAI分析 | ✕ |
| `/teams/[teamId]`<br>チーム管理画面 | チーム名・公開設定・招待コード再発行、メンバー一覧の閲覧・権限変更・追放（editorのみ）。NewRoundFabは表示しない | ✕ |
| └── TeamInviteCode | チーム名・公開設定・招待コード再発行 | ✕ |
| └── MemberList | メンバー一覧（全員閲覧可） | ✕ |
| └── MemberRoleControl | 権限変更・追放（editorのみ） | ✕ |
| `/teams`<br>公開チーム一覧・検索画面 | チーム参加・作成の起点。検索して参加、または`/teams/new`・`/teams/join/[code]`へ | ✕ |
| `/teams/new`<br>チーム作成画面 | チーム名・公開設定を入力してチームを作成 | ✕ |
| `/teams/join/[code]`<br>招待コード参加確認・処理画面 | 招待コードを（URLパラメータまたは`/teams`からの入力で）受け取り、確認のうえチームに参加 | ✕ |
| `/settings`<br>設定画面 | プロフィール・メール変更・アカウント削除・テーマ（ダークモード・アクセントカラー）・通知・言語等を1画面に集約 | ✕ |
| `/legal`<br>利用規約・プライバシーポリシー画面 | 規約・個人情報保護方針の表示 | ✕ |
| `/feedback`<br>不具合報告・要望フォーム | バグ報告・要望の送信 | ✕ |
