# Screen State (画面状態遷移図)

- `〇` テスト済み
- `△` テスト漏れ
- `⚠` 実装漏れ

## `/` 紹介画面

```mermaid
stateDiagram-v2
    direction LR
    [*] --> 紹介画面: 未認証
    [*] --> [*]: 認証済み<br/>（/roundsへ遷移）

    紹介画面 --> [*]: 開始ボタン<br/>（/signupへ遷移）
```

| イベント | 初期 |  | 紹介画面 |  |
| :--- | :---: | :---: | :---: | :---: |
| 未認証でアクセス | 紹介画面 | 〇 | - |  |
| 認証済みでアクセス | /roundsへ遷移 | 〇 | - |  |
| 開始ボタン | - |  | /signupへ遷移 | 〇 |
