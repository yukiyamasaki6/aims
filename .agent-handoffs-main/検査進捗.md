# 検査進捗

判定の基準、図の範囲、提示の単位は、検査計画.mdの第8節『検査の基準』に従う。シナリオの定義は、検査単位-シナリオ案.mdにある。

更新の方法: 各バッチの検査担当が、自分のバッチのシナリオの行の状態と判定の件数と備考を、作業の節目ごとに書き換える。指揮者は、ユーザーの確認結果に合わせて状態を更新し、バッチの終了時に判定の件数を確かめる。
シナリオの状態は、未着手、図の提示待ち、ユーザー確認待ち、判定済み、変更済みの順に進む。判定の件数は、判定済み以降に、必要、不要の疑い、判断できないの件数を数字で書く(未判定の間は-)。
共有される処理の表は、そのシナリオを検査するたびに、その場面の要否を記録して状態を『場面の記録中』にし、使う最後のシナリオで判定を確定して『確定済み』にする。
